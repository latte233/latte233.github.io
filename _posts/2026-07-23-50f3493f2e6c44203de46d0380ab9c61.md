## 重点信号详解

### Claude Sonnet 5

**象限**：Models & Research
**环位**：Adopt
**跨源热度分**：2.9

**是什么**：Anthropic 于 6/30 发布的中端旗舰模型，1M token 原生上下文窗口，128K 最大输出，性能逼近 Opus 4.8 但价格不到一半。

**为什么重要**：Sonnet 5 已成为 Claude Code 的默认模型，1M 上下文 + $2/$10 促销定价（8/31 前）直接改写了 Agent 应用的成本方程。对于每天发起成千上万次调用的 Agent 开发者，这不是"又强了多少"的问题，而是"谁还烧得起旗舰模型"的问题。

**当前状态**：已在 Claude Platform、Claude.ai、Claude Code 全面上线。促销期 $2/$10 每 Mtok，9/1 起恢复 $3/$15。支持 prompt caching（90% 节省）和 batch processing（50% 节省）。

**建议下一步**：团队应评估将 Sonnet 5 作为 Agent 应用的默认模型，在 8/31 促销期内完成性能基准测试和成本对比。

### Kimi K3

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：3.0

**是什么**：月之暗面 7/16 发布的 2.8T 参数开源模型，原生支持视觉理解和 100 万 token 上下文，登顶全球最大开源模型。

**为什么重要**：K3 发布后 48 小时内请求量逼近 GPU 集群上限，月之暗面被迫暂停新订阅。HN 帖子获 2082 分，成为本周社区讨论焦点。公司宣布拆分 Kimi Membership（Web/App/Work）和 Kimi Code Membership，以更精准匹配算力。

**当前状态**：新订阅暂停中，现有用户不受影响。正在扩容，计划分批恢复。Kimi Work 桌面 Agent 已上线，支持 WebBridge 浏览器自动化、K3 Swarm、Cron 和金融 API。

**建议下一步**：关注订阅恢复时间，恢复后立即申请试用。长上下文场景优先评估 K3，编码场景可关注 Kimi Code 独立订阅。

### MCP 协议 7/28 无状态化正式版

**象限**：Frameworks & Infrastructure
**环位**：Adopt
**跨源热度分**：3.0

**是什么**：MCP 将于 7/28 发布自诞生以来最大规模的规范修订——无状态化核心。移除 initialize 握手和 sessions，任何 MCP 请求可命中任意 Server 实例。

**为什么重要**：这是 breaking changes 级别更新。协议层会话被彻底移除，初始化握手消失，OAuth 要求显著收紧，三个核心功能被废弃。如果团队在生产环境运行 MCP Server，必须在 7/28 前完成迁移。

**当前状态**：Release Candidate 已于 5/21 发布，正式版 7/28 生效。官方提供了完整的迁移指南和 Breaking Changes 清单。

**建议下一步**：立即盘点团队所有 MCP Server，按官方迁移指南逐项检查。7/28 前完成灰度测试，确保正式版切换无中断。

### DeepSeek V4 模型名迁移

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：2.8

**是什么**：DeepSeek 旧模型名 deepseek-chat 和 deepseek-reasoner 将于 2026-07-24 15:59 UTC 后正式退役。所有调用必须迁移到 deepseek-v4-pro（推理）或 deepseek-v4-flash（对话）。

**为什么重要**：明天就是截止日。未迁移的 API 调用将直接报错。V4-Pro 为 1.6T MoE（49B 激活），V4-Flash 为 284B MoE（13B 激活），均支持 1M 上下文、MIT 开源、OpenAI/Anthropic API 格式兼容。

**当前状态**：V4 Preview 4/24 发布，7 月中旬正式版上线，采用峰谷分时定价。新账户赠送 500 万免费 token。

**建议下一步**：今天完成所有 deepseek-chat/reasoner 调用的模型名替换，灰度验证后全量切换。
