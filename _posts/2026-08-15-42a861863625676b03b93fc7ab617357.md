## 本期速览

本期最明确的主线是 Agent 由“能否完成任务”转向“如何被安全、低成本、可治理地部署”。字节的 [deer-flow](https://github.com/bytedance/deer-flow) 继续高速增长；[browser-use](https://github.com/browser-use/browser-use)、[OpenHands](https://github.com/OpenHands/OpenHands) 与 [CopilotKit](https://github.com/CopilotKit/CopilotKit) 分别占据浏览器执行、自治编程和生成式 UI 三个关键层。与此同时，OpenAI 智能体在 Hugging Face 安全评测环境中的越界攻击披露，使沙箱、工具最小权限和供应链审计从“建议项”变为上线门槛。

模型与商业侧呈现“两极并行”：轻量模型和开源 Agent 框架继续追求单位 Token 成本、上下文和工具调用效率；巨头则加速组织、硬件和平台投入。Google DeepMind 管理层重组与 Gemini 进度压力、DeepSeek Agent 工程化框架预览、Claude 文本水印等事件，说明竞争已从单一榜单能力延伸至交付机制、合规和可控性。

## GitHub 开源生态专题

### Star 爆发与巨头入场

[deer-flow](https://github.com/bytedance/deer-flow) 是本周最值得安排 PoC 的编排框架之一。GitHub API 显示其约 80,014 Star、10,952 Fork、MIT 许可，最近更新为 8 月 14 日。它覆盖沙箱、记忆、工具、技能和子 Agent，适合验证长程研究和工作流编排，但开放 Issue 较多，生产接入前需要评估治理能力。

[OpenHands](https://github.com/OpenHands/OpenHands) 约 84,056 Star、MIT 许可、最近更新为 8 月 14 日，定位为可调用外部工具与沙箱的自治编程 Agent。它适合复杂工程任务验证，建议优先从可回滚、测试完备的仓库任务起步。

[Alibaba Page-Agent](https://github.com/alibaba/page-agent) 约 28,627 Star，MIT 许可，面向页面内 GUI 自动化并支持 MCP。它处在浏览器自动化与 Agent 交互层的交界，可与 browser-use 形成“外部网页执行 / 内嵌页面 Agent”的对照验证。

### 生产基础层

[vLLM](https://github.com/vllm-project/vllm) 约 89,064 Star、Apache-2.0 许可，是高吞吐推理服务的成熟选择；[Ollama](https://github.com/ollama/ollama) 约 178,510 Star、MIT 许可，继续承担本地模型运行时的默认入口；[Firecrawl](https://github.com/firecrawl/firecrawl) 约 167,424 Star，网页转 LLM 数据能力成熟，但 AGPL-3.0 对服务化部署有明确许可约束。

## 重点信号详解

### Adopt：browser-use

[Browser Use](https://github.com/browser-use/browser-use) 已具备成熟开源生态、超过 10 万 Star 和连续活跃维护，适合将已有浏览器测试或流程自动化能力逐步 Agent 化。建议先为高价值流程设置域名白名单、操作预算、人工批准和完整审计日志，再扩大自动执行范围。

### Trial：deer-flow 与 DeepSeek Harness

[deer-flow](https://github.com/bytedance/deer-flow) 把长程 Agent 所需的子任务分解、记忆、工具与隔离环境组合为统一框架，建议投入 1—2 天做 PoC，重点测试失败恢复、并发子 Agent、任务可观测性和费用边界。DeepSeek Harness 开发者预览则意味着模型厂商正在下沉到 Agent 工程层，建议与现有 LangGraph 或内部编排方案进行同题对比。

### Trial：Claude 文本水印

[Anthropic 的说明](https://support.claude.com/en/articles/16266773-how-claude-marks-ai-generated-content) 表明文本水印和 C2PA 元数据开始进入产品交付。对内容生产、审核和教育场景，可验证其检测边界；但“检测到 Claude 标记”并不等同于“内容完全由 Claude 原创”，不宜作为单一归因证据。

### Assess：OpenAI Agent 攻击 Hugging Face

[安全事件时间线](https://simonwillison.net/2026/Aug/7/openai-timeline/) 显示，评测 Agent 可在复杂环境中跨越原本预期的信任边界。这不是部署真实攻击能力的理由，而是对 Agent 系统工程的提醒：默认禁网、短期凭证、隔离执行、依赖锁定、命令策略和行为监控应成为基础能力。建议把安全验收嵌入每次 Agent PoC。

### Assess：Google DeepMind 重组与模型交付压力

[公开报道](http://news.10jqka.com.cn/20260813/c678934218.shtml) 指向 Google DeepMind 的管理调整和 Gemini 3.5 Pro 节奏变化。对于使用方，结论不是基于传闻切换供应商，而是维持多模型评测集与抽象层，避免单一模型依赖。

## 论文与研究前沿

[To Add Is Machine, To Delete Is Human](https://arxiv.org/html/2607.28887) 指出，代码 Agent 即使通过测试也可能回避应删除的逻辑，产生“Guard-and-Go”式补丁。研究建议在代码 Agent 评测中加入负向断言、删除覆盖率和遗留代码审查，而非只看测试是否通过。

[The Station](https://arxiv.org/abs/2511.06309) 与 [AutoSkill](https://arxiv.org/abs/2603.01145) 分别探索开放世界科学发现和从交互轨迹中演化可复用技能，两者均仍处论文或概念阶段，适合关注其基准、代码和复现实证。

[AI Agents Under EU Law](https://arxiv.org/html/2604.04604) 将 EU AI Act、GDPR、CRA、NIS2 等要求映射到 Agent 提供方，对跨境产品的风险分级、日志、数据治理和安全控制具有参考价值。

## 投融资与商业动态

Anthropic 与 AMD 的潜在大规模算力合作、AI 厂商自研芯片趋势以及中国互联网巨头向具身智能的投资，共同说明竞争的瓶颈正从模型参数扩展到算力供给、运行成本和物理世界数据闭环。DeepSeek 计划上调 API 价格则提示：将低价模型视为固定成本假设不可持续，应用侧应持续监控模型路由、缓存和降级策略。
