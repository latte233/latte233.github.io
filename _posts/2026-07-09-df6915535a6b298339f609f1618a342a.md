## 重点信号详解

### GPT-5.6 系列全球公开发布

**象限**：Models & Research
**环位**：Trial（⬆️ 从 Assess 升级）
**跨源热度分**：3.0

**是什么**：OpenAI GPT-5.6 系列（Sol/Terra/Luna）于 7 月 9 日全球公开发布，结束了自 6 月 26 日发布以来为期 13 天的受限预览。Sol 在 Terminal-Bench 2.1 达到 91.9%，网络安全 CTF 命中率 96.7%；Terra 性能持平 GPT-5.5 但价格减半；Luna 提供最低成本选项。同时发布 GPT-Live 语音模型，支持全双工实时对话。

**为什么重要**：GPT-5.6 Sol 是目前公开可用模型中编程能力最强的之一，其 ultra 子智能体协作模式和 max 深度推理模式直接对标 Claude Fable 5 的 Agent 能力。价格与 GPT-5.5 持平意味着迁移成本低，对已在 GPT-5.5 上的团队是平滑升级。GPT-Live 的全双工能力可能改变语音交互的产品形态。

**当前状态**：7 月 9 日起全球开放 API 和 ChatGPT 访问。Sol 定价 $5/$30 per million tokens（输入/输出），Terra 定价更低，Luna 为经济档。GPT-Live-1 和 GPT-Live-1 mini 同步上线。

**建议下一步**：立即在现有 GPT-5.5 工作流中测试 Sol 的编程和 Agent 能力提升；评估 GPT-Live 在语音交互场景的可行性；关注 Cursor/Claude Code 等工具对 GPT-5.6 的集成进度。

### OpenClaw — 本地优先个人 AI 助手

**象限**：Tools & Products
**环位**：Trial（🆕 新进雷达）
**跨源热度分**：2.8

**是什么**：OpenClaw 是一个开源的个人 AI 助手框架，运行在用户自己的设备上，通过已有的聊天工具（WhatsApp、Telegram、Discord、飞书等 50+ 渠道）进行交互。支持语音唤醒、文件管理、浏览器操作、多 Agent 管理等能力，所有数据本地处理。

**为什么重要**：OpenClaw 代表了 AI 助手从"独立 App"向"融入已有工作流"的范式转变。382K Star 和 100+ contributors 说明社区认同度极高。对于注重数据隐私的企业和开发者，本地优先架构是一个重要选项。

**当前状态**：MIT 协议（但 GitHub 标注 NOASSERTION，需进一步审查），TypeScript 编写，支持 macOS/iOS/Android，有 3000+ 社区技能模块。本周 100+ commits 表明开发非常活跃。

**建议下一步**：审查 License 具体条款；在非生产环境中部署 PoC，测试飞书渠道集成和数据隔离方案；评估与现有内部工具链的整合可能性。

### MCP 2026-07-28 规范正式版

**象限**：Frameworks & Infrastructure
**环位**：Adopt（维持）
**跨源热度分**：2.5

**是什么**：MCP 协议史上最大规模修订正式版将于 7 月 28 日发布。核心变更包括：架构去状态化（移除 Session ID，改用请求自包含路由）、新增 Extensions 框架、鉴权向 OAuth 2.1/OIDC 对齐。这是 Breaking Change，现有 MCP Server 需要适配。

**为什么重要**：MCP 已成为 AI 工具互操作的事实标准，被 Anthropic、OpenAI、Microsoft、Google 等主要厂商采纳。去状态化改造将显著降低部署复杂度，使负载均衡无需会话亲和性。但 Breaking Change 意味着所有现有实现都需要更新。

**当前状态**：[modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers) 88,228 Star，100 contributors，本周 19 commits。正式版发布倒计时 19 天。

**建议下一步**：审查现有 MCP Server 实现的兼容性；制定 7 月 28 日后的升级计划；关注官方迁移指南发布。
