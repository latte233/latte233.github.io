## 重点信号详解

### Grok Build 开源（xAI 首次放出一个 Coding Agent Harness）

**象限**：Frameworks & Infrastructure
**环位**：Trial
**跨源热度分**：2.9

**是什么**：xAI 把内部 Grok 4.3 Coding Agent 的全套 Harness、TUI 和 Agent Client Protocol（ACP）实现以 Apache 2.0 完整开源到 [xai-org/grok-build](https://github.com/xai-org/grok-build)。

**为什么重要**：这是 Musk 系公司第一次以工业级完整度（Rust + 鼠标交互 TUI + ACP 编辑器嵌入 + Headless CI 模式）开源一个 Coding Agent 基础设施，让社区能直接看到顶级商业 Agent 的工程实现；同时 xAI 明确「关闭默认数据留存、删除历史编码数据」的隐私姿态，把竞品（尤其 OpenAI、Anthropic）都拉到桌面对齐。

**当前状态**：4 天 16.4k Star、3.0k Fork；Rust 单一语言；Apache-2.0；但 issues/PR 关闭未给社区开放入口，暂由 xAI 单方 commit；尚无 Release 版本。

**建议下一步**：1-2 天研究代码结构，重点看它怎么处理 Tool Use 编排和 ACP 协议；如果团队在做 Agent 工具链或要嵌入自家 IDE，可以拿它做 1 天 PoC；但不要急着 commit production 用——等 Release 节奏稳定。

### DeepSeek V4 正式版双协议发售（V4-Pro 1.6T + V4-Flash 284B，首次峰谷定价）

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：2.8

**是什么**：[DeepSeek V4 7 月 17 日正式版双版本齐发](https://deepseek-ai.net/zh-cn/blog/deepseek-v4-release/)，Pro 1.6T 参数 / Flash 284B，全系 MIT 开源，[CSA+HCA 混合注意力](https://cloud.tencent.cn/developer/article/2661839)，支持百万 token 上下文，编程能力据称可对标 OpenAI/Anthropic 旗舰。

**为什么重要**：开源社区第二次拿到「足以和闭源顶级模型对抗的旗舰权重」；它的峰谷定价机制（API 闲时折扣高达 75%）是定价模式上的首创，可能重塑 API 计费模型；国产芯片（昇腾、寒武纪）首日适配。

**当前状态**：Codeforces 3206、LiveCodeBench 93.5% 超过 Claude Opus 4.6；社区已经有 70+ 部署测评；HuggingFace 已开放完整权重。

**建议下一步**：评估是否将 V4-Flash 接入到次要编程场景（成本比 Opus 4.8 低 70 倍）；如果有 8-32 卡 H20 国产 GPU 环境，可以做 V4-Pro 私有化部署验证。

### MCP 协议 2026-07-28 大版本即将发布，无状态化是最大变革

**象限**：Frameworks & Infrastructure
**环位**：Adopt
**跨源热度分**：2.7

**是什么**：[MCP 2026-07-28 Spec RC](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/) 已锁定，正式版 7 月 28 日发布。核心变化：无状态化、Extensions 框架、Tasks、MCP Apps、授权加固、正式弃用策略。

**为什么重要**：这是 MCP 自 2024 年发布以来最大幅度的协议改版，让它真正可以部署到企业级 production（无状态、云原生）；同时引入 MCP Apps 让「Agent 调用 Agent」成为标准模式。值得注意的是 [中国云厂商已经在 2026 AI Infra 大会上宣布 60% 的财富 500 强把 MCP 当内部标准](https://cloud.tencent.com/developer/article/2707609)。

**当前状态**：RC 已冻结，[4sysops 详细说明](https://4sysops.com/archives/2026-07-28-model-context-protocol-mcp-stateless-multi-round-trip-routable-headers-authorization-hardening/)；FastAPI MCP、fastmcp 等头部库都已表态跟进。

**建议下一步**：如果团队在生产环境跑 MCP Server，这周就把 RC Breaking Changes[读完并评估迁移成本](https://blog.csdn.net/weixin_45463545/article/details/162455693)；预备 1 周迁移窗口。
