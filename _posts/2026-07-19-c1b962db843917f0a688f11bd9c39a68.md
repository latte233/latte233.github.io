## 本期速览

本周 AI 行业的核心叙事是「Agent 基础设施化」——GitHub 周榜 Top 10 项目几乎拼出了一张完整的 Agent 工作流地图，从文件操作（OfficeCLI）、视频理解（claude-video）、会议纪要（Meetily）到多 Agent 调度（orca、herdr），开源圈已从"模型有多强"全面转向"怎么让模型稳定进入工作流"。

Grok Build 开源事件持续发酵：Star 从上周 16,399 涨到 18,750，但被曝出开源前曾静默上传用户完整代码树，xAI 在争议中仓促开源。这是本周最值得警惕的信号——开源不等于安全，代码透明后才暴露了"traffic analysis"外衣下的整库上传行为。

WAIC 2026 进入第二天（7/18），核心信息清晰：AI Agent 取代基础模型成为展台绝对主角，具身智能从 Demo 走向真实场景落地，蚂蚁灵波开源 LingBot-VLA 2.0 覆盖 17 家机器人厂商 20 种构型。MCP 协议 7/28 正式版发布倒计时 9 天，无状态化重构是 MCP 发布以来最大修订。

OpenCut 以 75K Star 成为本周最值得关注的新品类——开源 CapCut 替代品正在从零重写，原生集成 MCP 协议让 AI Agent 直接操控剪辑流程，代表了"创作工具 + Agent 协议"融合的新方向。

## 重点信号详解

### Grok Build 隐私争议与开源

**象限**：Frameworks & Infrastructure
**环位**：Trial
**跨源热度分**：2.9

**是什么**：xAI 的 Coding Agent Harness 在 7/14 被研究员发现静默上传用户完整工作目录（以"traffic analysis"为名），7/16 xAI 仓促以 Apache-2.0 全量开源 84 万行 Rust 代码。本周 Star 从 16,399 涨到 18,750。

**为什么重要**：这是 AI Coding Agent 领域首次重大隐私事件。开源后代码可审计，但暴露了一个核心问题——Coding Agent 拥有完整文件系统访问权限，如果存在遥测后门，用户的整个代码库都可能被外泄。这直接影响企业在选择 Coding Agent 时的信任模型。

**当前状态**：Apache-2.0 开源，但仅 1 个贡献者，无 Release，社区贡献尚未打开。Star 增速从首日爆发后趋缓（本周 +2,351 vs 上周 4 天 +16,399）。

**建议下一步**：如果团队考虑使用 Grok Build，务必审查其网络通信代码，确认无遥测后门。建议等待社区贡献打开和首个 Release 发布后再做生产评估。同时借此事件审视团队现有 Coding Agent 的数据流向。

### OpenCut — MCP 原生集成的创作工具

**象限**：Frameworks & Infrastructure
**环位**：Trial
**跨源热度分**：2.6

**是什么**：75K Star 的开源 CapCut 替代品，正在从零重写为 Rust 核心 + MCP 原生集成的跨平台创作系统。支持 Web、桌面和移动端，让 AI Agent 直接操控视频剪辑流程。

**为什么重要**：OpenCut 是首个把 MCP 协议写进架构而非事后补丁的视频编辑器。这意味着 AI Agent 可以通过标准协议直接操控时间轴、添加特效、导出视频——创作工具正在从"人操作软件"变成"Agent 操作软件，人监督结果"。

**当前状态**：MIT 许可，100+ 贡献者，旧版已 archived，新版重写中（最后 Release 2026-04-15）。fal.ai 赞助支持第三方生成模型接入。

**建议下一步**：关注重写完成后的首个正式 Release。如果团队有视频处理自动化需求，可提前研究其 MCP 接口设计。

### MCP 协议 7/28 正式版发布

**象限**：Frameworks & Infrastructure
**环位**：Adopt
**跨源热度分**：3.0

**是什么**：MCP 协议自发布以来最大规模修订，7/28 正式发布。核心变化：协议层移除会话状态（stateless core）、初始化握手取消、引入 Extensions 框架和 Tasks 扩展、OAuth 2.1 对齐授权强化、12 个月正式废弃策略。

**为什么重要**：这是 AI 工具互操作性的基础设施升级。无状态化意味着任何 MCP 请求可以命中任意服务器实例，大幅简化部署和扩展。但同时也意味着现有 MCP Server 需要迁移——握手消失、session ID 移除、三个核心功能被废弃。

**当前状态**：Release Candidate 已于 5/21 锁定，10 周 SDK 验证窗口即将结束。维护者 David Soria Parra 和 Den Delimarsky 主导。

**建议下一步**：如果团队维护 MCP Server，立即开始迁移评估。7/28 后旧协议进入 12 个月废弃倒计时。梳理依赖的 MCP 功能是否在废弃列表中。

### WAIC 2026 — Agent 取代模型成为主角

**象限**：Practices & Ecosystem
**环位**：Assess
**跨源热度分**：2.6

**是什么**：2026 世界人工智能大会 7/17-20 上海举行，1100+ 企业参展，300+ 产品全球首发。第二天（7/18）核心信息：AI Agent 取代基础模型成为各家展台绝对主角，具身智能从 Demo 走向真实场景。

**为什么重要**：WAIC 是中国 AI 产业的风向标。今年从"模型参数比拼"切换到"Agent 商业化落地"，与 GitHub 开源圈的 Agent 基础设施化趋势完全吻合。蚂蚁灵波开源 LingBot-VLA 2.0、腾讯发布 Gravity"双脑"框架、魔芯 Flash World Model 降本 70%——具身智能正在从实验室走向工厂、药房、厨房。

**当前状态**：大会进行中（7/17-20），预计闭幕日还将有更多发布。

**建议下一步**：关注 WAIC 闭幕日（7/20）的首发产品清单。如果团队有具身智能或 Agent 落地需求，LingBot-VLA 2.0 值得评估。
