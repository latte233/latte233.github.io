## 重点信号详解

### MCP 协议无状态化正式版

**象限**：Frameworks & Infrastructure

**环位**：Adopt

**跨源热度分**：3.0

**是什么**：MCP 协议将于 7/28 发布史上最大规模修订，核心变更为协议层全面无状态化——移除 Session ID 和握手流程，改用请求自包含路由。同时引入 Extensions 框架、Tasks 扩展、MCP Apps 和 OAuth/OIDC 授权加固。

**为什么重要**：这是 MCP 自 2024 年 11 月发布以来最大的 breaking change。无状态化使负载均衡不再需要会话亲和性，直接降低企业级部署的运维复杂度；但所有现有 MCP Server 实现都需要适配。

**当前状态**：Release Candidate 已于 5/21 锁定，最终规范 7/28 正式发布。

**建议下一步**：立即盘点团队所有 MCP Server 实现，在 7/28 前完成无状态化适配，重点检查 Session ID 移除和 OAuth 流程变更。

### ECC（Everything Claude Code）

**象限**：Frameworks & Infrastructure

**环位**：Trial

**跨源热度分**：2.8

**是什么**：Anthropic 黑客松冠军项目，定位为 Agent Harness 性能优化系统。它将技能、长期记忆、安全规则、工作流和自动化机制收敛为一套可复用的规范，支持 Claude Code、Codex、Cursor、OpenCode、Gemini、Zed 和 GitHub Copilot。

**为什么重要**：它代表了一条不同于「再造一个 Agent」的路径：通过跨 Harness 的统一抽象层，提升既有 AI 编程工具的使用效率。23 万 Star、100+ Contributors 和 112 个 Open Issues 表明其社区热度与治理质量兼具。

**当前状态**：MIT 协议开源，每日活跃迭代；v2.0.0-rc.1 已发布，引入 Hermes operator 层。

**建议下一步**：选取一个 Claude Code 或 Codex 项目做 PoC，安装 ECC 技能包后对比开发效率变化，重点验证 skills 和 subagents 对现有团队工作流的适配度。

### Kimi K3

**象限**：Models & Research

**环位**：Trial

**跨源热度分**：3.0

**是什么**：月之暗面于 7/16 发布的 2.8 万亿参数开源大模型，采用 KDA 注意力机制，是目前全球最大参数规模的开源模型。

**为什么重要**：上线 48 小时就因算力告急暂停 C 端新用户订阅，显示需求远超预期。其在前端代码、百万上下文等能力上登顶评测榜单，直接对标 GPT-5.6 和 Claude Opus 4.8。

**当前状态**：开源权重可下载，C 端订阅仍暂停。官方正扩容，并计划拆分 Kimi Membership 和 Kimi Code Membership。

**建议下一步**：关注订阅恢复时间；有前端代码生成或长上下文需求的团队可准备 benchmark 方案，订阅恢复后进行对比。

### DeepSeek V4 API 迁移

**象限**：Models & Research

**环位**：Trial

**跨源热度分**：2.8

**是什么**：DeepSeek 旧模型名 deepseek-chat 和 deepseek-reasoner 将于 7/24 15:59 UTC 正式退役，需迁移到 V4-Flash 或 V4-Pro。

**为什么重要**：迁移截止日仅剩 2 天，未迁移服务将直接中断。V4 系列在 Agent 场景上优化，并支持 1M 上下文、OpenAI Chat Completions 和 Anthropic API 格式。

**当前状态**：迁移窗口内旧模型名自动路由到 V4 服务。

**建议下一步**：立即检查所有使用旧模型名的服务，完成模型名、thinking 参数和长上下文行为验证。

### Gemini 3.6 Flash

**象限**：Models & Research

**环位**：Assess

**跨源热度分**：2.7

**是什么**：Google DeepMind 于 7/21 发布的新一代 Flash 主力模型，编码和 Agent 规划能力提升，输出 token 消耗减少 17%。同步发布 3.5 Flash-Lite 和仅面向可信伙伴的 3.5 Flash Cyber。

**为什么重要**：在价格不变的前提下刷新了轻量模型的编码和 Agent 能力，直接对位 GPT-5.6 Luna 与 DeepSeek V4-Flash；1M 上下文和 Computer Use Preview 是差异化亮点。

**当前状态**：已 GA，API 价格为每百万 tokens 输入 $1.50、输出 $7.50，已加入 Google Antigravity 2.0。

**建议下一步**：对编码和 Agent 任务做 benchmark，特别验证 token 效率收益；现有 Gemini 3.5 Flash 用户可评估升级成本收益。
