## GitHub 开源生态专题

### Star 爆发项目

本期无 7 天 Star 增量 > 2000 的爆发级项目，但 Ponytail（+638/周）和 Graphify（+1,286/周）仍保持稳健高增长。

### 细分领域新秀

**Spec-Driven Development（规格驱动开发）**

本周这一新兴范式持续爆发。[github/spec-kit](https://github.com/github/spec-kit)（121,792 Star，GitHub 官方出品）让开发者在编码前先写规格文档，支持 30+ AI 编码助手基于规格生成代码。[Fission-AI/OpenSpec](https://github.com/Fission-AI/OpenSpec)（61,061 Star）是社区侧的同类框架。二者共同代表了"先写 spec 再写 code"的开发范式变革，推荐环位：spec-kit Trial / OpenSpec Assess。

**代码知识图谱**

[Graphify](https://github.com/Graphify-Labs/graphify)（89,011 Star，+1,286/周）将代码库转为知识图谱表示，71.5x token 减少率使 AI 编码助手在大型代码库上的效率显著提升。[CodeGraph](https://github.com/colbymchenry/codegraph)（60,192 Star）为同赛道竞品，推荐环位：Graphify Trial / CodeGraph Assess。

**Agent 安全与治理**

[microsoft/agent-governance-toolkit](https://github.com/microsoft/agent-governance-toolkit)（4,888 Star）提供 OWASP Agentic Top 10 对齐的 Agent 治理工具包，[destructive_command_guard](https://github.com/Dicklesworthstone/destructive_command_guard)（4,755 Star）用 Rust 编写，阻止 Agent 执行危险 git/shell 命令。二者反映了 Agent 安全方向从"讨论"走向"工具化"。

## 重点信号详解

### Gemini 3.5 Pro 正式发布

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：2.8

**是什么**：Google DeepMind 于 7/17 正式发布 Gemini 3.5 Pro，这是一次全新预训练而非 2.5 Pro 的微调升级，2M token 上下文窗口为当前量产级最大，配备 Deep Think 推理模式。

**为什么重要**：这是 Google 在连续跳票后的正面回击。全新预训练底座意味着模型能力存在不可预测的跳变空间，泄露信息显示前端代码生成能力已超越 Fable 5。2M 上下文窗口为实际业务中的超长文档处理、完整代码库理解提供了闭源模型中最大的窗口。

**当前状态**：7/17 GA 上线，API 预估定价 $1.25/$10/M tokens（输入/输出），Deep Think Ultra 套餐 $250/月。尚未正式确认所有规格。

**建议下一步**：在团队测试场景中对比 Gemini 3.5 Pro 与 GPT-5.6 Sol、Claude Opus 4.8 在代码生成和长文本理解任务上的表现，重点验证 2M 上下文窗口的实际效果。

### DeepSeek V4 正式版

**象限**：Models & Research
**环位**：Trial（从 Assess 升级 ⬆️）
**跨源热度分**：2.7

**是什么**：DeepSeek V4 正式版分 Pro（1.6 万亿参数）和 Flash 双版本同步上线，全系标配 100 万 token 上下文，首创峰谷定价机制——高峰时段 API 价格为平时的 2 倍。

**为什么重要**：DeepSeek 通过峰谷定价在保持极致性价比的同时解决了算力资源调度问题，这是 API 定价策略的创新。V4 Pro 1.6 万亿参数的推理计算量据称仅为同等规模模型的 1/10，Agent 编码与世界知识能力达到国内与开源领域领先水平。

**当前状态**：7/15 已在腾讯云 TokenHub 等渠道上线，7/17 全面商用。谷时调用算力费直降约 60%。

**建议下一步**：对于成本敏感的 Agent 类应用，建议在谷时段接入 V4 Flash 做 PoC，对比 GPT-5.6 Terra 的性价比。

### MCP 协议 2026-07-28 正式版

**象限**：Frameworks & Infrastructure
**环位**：Adopt
**跨源热度分**：2.8

**是什么**：MCP 规范 2026-07-28 RC 已锁定，这是 MCP 自 2024 年发布以来最大规模修订：协议层彻底无状态化、Extensions 成为一等公民、Tasks 扩展支持长任务、新增 MCP Apps 概念、OAuth/OIDC 授权加固。

**为什么重要**：无状态架构意味着任何 MCP 请求可以打到任意服务器实例，水平扩展能力大幅提升。Extensions 框架让 MCP 生态从"硬编码"走向"可插拔"。7/28 正式版发布后，现有的有状态实现有 12 个月的迁移窗口。

**当前状态**：RC 已发布，7/28 正式版倒计时 11 天。微软、OpenAI、Google 均已参与 MCP 贡献。

**建议下一步**：已有 MCP 实现的团队应立即阅读 RC 变更日志，评估迁移工作量；新项目直接基于 2026-07-28 规范构建。
