## 重点信号详解

### Claude Fable 5.1 / Mythos 5.1 双旗舰发布

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：2.8

**是什么**：Anthropic 于 9-1 发布新一代双旗舰，Simon Willison 首发实测，HN 858 分 813 评，为本周讨论量最大的单一事件。

**为什么重要**：新基准 Terminal-Bench-Science 0.1 上 Fable 5.1 得分 52.6%（前代 24.7%），科研与长任务能力翻倍式跃升；同期 Sonnet 5 折扣期结束、周限额口径调整，Claude 系成本结构同步变化。

**当前状态**：已可用（API + Claude 全端），官方公告与多家独立媒体确认，价格与限额细则已落地。

**建议下一步**：安排 1-2 天用现有业务 prompt 集做 Fable 5.1 对比回归；同时按新限额/新 token 膨胀系数重算月成本。

### 腾讯混元 Hy4 preview 770B 开源

**象限**：Models & Research
**环位**：Trial（⬆️ Watch → Trial）
**跨源热度分**：2.7

**是什么**：上期连续两期单源的「混元 770B」传闻证实落地：770B 总参/激活 49B/1M 上下文，Apache 2.0 全量开源，权重上架 HF/GitHub/魔搭。

**为什么重要**：Terminal-Bench 2.1 = 85.4、SWE-bench Multilingual = 82.9 均为开源第一；发布当日 API 排队 5000+，FlagOS 已完成五款国产芯片适配并上线 INT8 镜像，国产算力可部署性明确。

**当前状态**：权重可用、License 商业友好、多平台镜像就绪；8-31 因调用激增紧急扩容。

**建议下一步**：有国产算力或超长上下文需求的团队安排一次 1M 上下文场景 PoC。

### Claude Code Opus 5 Auto Mode 提示注入攻击实证

**象限**：Practices & Ecosystem
**环位**：Trial（维持）
**跨源热度分**：2.4

**是什么**：Rehberger（embracethered）发布完整攻击链长文，HN 393 分 119 评，Auto Mode 可被提示注入绕过并执行非预期命令。

**为什么重要**：叠加 Trail of Bits「VM 隔离不住 cyber-capable agents」与 ChainDrop npm 蠕虫（经 VS Code/Cursor/Claude Code 扩展钩子植入后门），Agent 执行环境的信任边界本周被系统性质疑。

**当前状态**：攻击细节公开、复现门槛低，官方暂无针对性修复公告。

**建议下一步**：对使用 Auto Mode/扩展机制的团队做一次注入面排查；将「扩展来源白名单」纳入研发规范。

### OpenClaw 2.0 持续迭代

**象限**：Frameworks & Infrastructure
**环位**：Trial（维持）
**跨源热度分**：2.6

**是什么**：2.0 发布后节奏未减：新博文《openclaw-2-accidentally》（HN 147 分）+ v2026.8.2，主仓库 388,521★（周 +230）、100+ 贡献者。

**为什么重要**：仍然是个人 Agent 基础设施事实上的标杆，2.0 的记忆/权限/多 Agent 协作重构正在被社区快速吸收。

**当前状态**：两周连发两版，MIT，迭代健康度满分。

**建议下一步**：已部署 1.x 的团队评估 2.0 迁移成本，重点回归记忆与权限行为差异。

### DeepSeek Harness 生态爆发

**象限**：Frameworks & Infrastructure
**环位**：Trial（维持）
**跨源热度分**：2.3

**是什么**：npm 周下载 60.5 万次，GitHub 195,077★（周增 3,366），插件兼容性治理启动。

**为什么重要**：Harness 生态的使用率指标（下载量）显著快于 Star 增速，说明从「围观」进入「实际采用」阶段。
