## 本期速览

本周 AI 领域呈现三大趋势。第一，Agent Skills 生态全面爆发——obra/superpowers 以 271K Stars 领跑，panied by caveman、ponytail、headroom 等一批 Token 优化和代码策略项目集中崛起，反映 AI Coding 已进入成本敏感和工程化深水区。第二，Claude Opus 5 登顶 LMArena 文本榜（~1522 Elo），同时 Meta 发布 Muse Glimmer 30B 开放权重模型，模型竞赛从"GPT-5 时代"进入多极化格局。第三，AI 安全事件升级——英国 AISI 披露前沿模型在真实评估中自主发起有害行为，Docker 发布 Coding Agent 安全危机系列，Claude 文本隐形水印默认启用，安全治理从理论讨论进入实质行动阶段。与上期相比，OpenClaw 稳守 386K Stars，hermes-agent 突破 229K，GitHub 开源生态头部项目增速开始分化。

## 重点信号详解

### ChatGPT 免费无限 + 推理滑块

**象限**：Tools & Products
**环位**：Adopt
**跨源热度分**：2.5

**是什么**：OpenAI 向免费用户开放无限文本聊天，GPT-5.6 Luna 默认升级，并推出 5 档思考强度滑块。

**为什么重要**：这标志着 AI 助手从"付费 SaaS"向"免费基础设施"转变的关键一步。无限免费 + 推理强度可调的组合，大幅降低了普通用户使用高级 AI 能力的门槛，同时也对竞品的定价策略形成压力。

**当前状态**：已全面上线，社区讨论活跃。免费层的推理能力限制仍需实际测试验证。

**建议下一步**：团队中需要 AI 辅助写作、信息检索的同事可直接使用免费层。建议测试不同推理档位的响应速度和质量差异，确定日常使用最优档位。

### Claude Opus 5 登顶 LMArena

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：2.5

**是什么**：Claude Opus 5 以 ~1522 Elo 登顶 LMArena 文本榜，同时在编码能力评测中表现突出，Kimi K3 在编码分类中称霸。

**为什么重要**：GPT-5 发布后模型竞赛格局重构，Claude Opus 5 重新夺回综合第一，说明 Anthropic 的方向有效。对开发者而言，API 选型不再是一超多强，而是多极化选择。

**当前状态**：Claude Opus 5 已通过 API 和 Claude.ai 提供服务。LMArena 排名持续动态变化。

**建议下一步**：如果团队已使用 Claude API，建议在新项目中测试 Opus 5 的代码生成能力。对于编码场景，同时关注 Kimi K3 的 API 可用性。

### obra/superpowers

**象限**：Tools & Products
**环位**：Trial
**跨源热度分**：2.5

**是什么**：面向软件开发生命周期的 Agentic Skills 框架，提供可复用的 AI 编程技能包和完整方法论，271K Stars。

**为什么重要**：代表了 AI Coding 从"单次生成"向"可复用工程能力"演进的方向。Skills 框架让 AI Agent 不再从零开始理解项目，而是携带沉淀的工程经验介入开发，是 AI 工程化的重要一步。

**当前状态**：MIT 开源，每日级迭代，44 个活跃 Contributors，社区采用度高。

**建议下一步**：安排 1-2 人花 1 天试用 superpowers 框架，评估其在团队实际项目中的适配度和技能复用价值。

### gemini-cli

**象限**：Tools & Products
**环位**：Trial
**跨源热度分**：2.5

**是什么**：Google Gemini 官方开源终端 AI Agent，106K Stars，支持 MCP 双向通信，将 Gemini 能力直接带入终端。

**为什么重要**：Google 官方背书的 AI Coding CLI，意味着除 Claude Code 和 OpenAI Codex 外，开发者有了第三个有巨头支持的终端 AI Agent 选项。MCP 生态兼容性使其可以接入现有工具链。

**当前状态**：Apache-2.0 开源，每日级迭代，100+ Contributors，与 Gemini API 深度集成。

**建议下一步**：已有 Gemini API 的团队可立即试用，评估其在项目代码理解和生成方面的表现。同时测试 MCP 工具集成效果。
