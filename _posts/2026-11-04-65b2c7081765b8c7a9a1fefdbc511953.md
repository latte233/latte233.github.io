## 重点信号详解（Adopt / Trial）

### 1. 权重空间编程（Trial 🆕 🔥 本周最大新范式）
[MIT 团队用 GPT-6 Astra 改写 Qwen3.5-0.8B 仅 0.016% 权重](https://honnibal.dev/blog/astra-read-write-misleading)，MATH-500 从 7.9% 升至 48.1%——意味着强模型可以直接「编辑」弱模型的权能，开放模型从「可部署」变成「可改写」。但 HN [辟谣帖 872 分](https://honnibal.dev/blog/astra-read-write-misleading)指出宣传误导（改写效果依赖特定基准与精心构造的权重定位），[Simon Willison 复现 457 分](https://simonwillison.net/2026/Nov/3/qwen-can-interpret-model-weights/)给出更克制的结论：小模型确实能解读模型权重，但距离「编程权重」尚远。**建议下一步**：研究侧跟踪原论文与复现差距；工程侧暂不投入，等独立复现（MATH-500 之外的任务面）再评估。

### 2. Claude Fable 5.5 / Mythos 5.5（Trial ⬆️）
从上周「疑似泄露」升级为「半公开」：[官网 HTML 泄露 Mythos 5.5（无护栏特种版）后 Anthropic 删页](https://finance.sina.com.cn/tech/roll/2026-11-02/doc-inixicic0508935.shtml)；[Fable 5.5 以 Opus 5.5 随机路由形式被实测](https://baijiahao.baidu.com/s?id=1880817065956756098)——one-shot 纯代码生成 66 秒动画短片、3D 版我的世界，传 1M 输入/$10/$50 定价；「53 分钟攻破 Linux 内核」传闻无法核验。注意证伪面：网传 14T 权重仓库被几十行 Python 证明是随机数。**建议下一步**：Anthropic IPO（11-19/20）前后大概率官宣，届时统一评测；勿据泄露信息做架构决策。

### 3. GPT-6.1 Terra 全量 + 6.2 Astra 灰测（Trial ✅ 兑现）
上期待核实项兑现：[Terra 全量推送并上线 Amazon Bedrock GA](https://my.oschina.net/u/9487999/blog/19782706)——$1/$5 每百万 token（较上代降 50%）、1.05M 上下文、Agents' Last Exam 60.0 分超 Astra，单任务成本 $0.29 为 Astra 的 1/16；gpt-6.2-astra 仍占 Codex 后台 19.8% 流量、未官宣。**建议下一步**：中端高频业务立即切换 Terra 验证性价比；Codex 团队持续观察灰度行为差异。

### 4. Gemini 4 Carbon（Trial，盲测确认）
[LMArena 文本总榜 1528 分登顶](https://finance.sina.com.cn/wm/2026-10-29/doc-iniwvwri5411663.shtml)、AA-Omniscience v1.1 幻觉测试第一——上周 AA 智能指数第一获盲测侧确认。但 [Gemini API 未开放](https://www.cnblogs.com/vibecodinghuanzhe/p/23477082)（仅网安防御方与 Fairwind 伙伴可用），社区实测编码维度仍落后 Opus 5.5 约 5 个百分点。**建议下一步**：长流程编码暂缓切换，等 API 开放后按官方定价（2/2/10）与 Terra 对位测试。

### 5. Mistral Large 4 开放权重（Trial ⬆️ ✅ 兑现追认）
[10-29 开放权重](https://www.163.com/dy/article/LANNBAHL05561FZD.html)：1.05 万亿参数 MoE（激活约 50B）、1M 上下文、原生多模态、FP8 检查点约 1061GB、修改版 MIT（MaaS 需授权）。AA 26 分为「中国以外最强开源」，但比 DeepSeek V4.1 Flash/GLM-5.3 低 6 分；FrontierCode 2.0 自报 19.7% 为开放权重最高、独立复现未完成。**建议下一步**：上期衰减预警解除；关注独立复现结果再决定是否进入推理集群。

### 6. Kimi K3.1 Pro 权重（Trial ⏳ 兑现待确认）
官方承诺 11-04 前开放完整权重（2.8T 总参/104B 激活/1M 上下文）。[当日扫描未见 HF 放出确证](https://www.163.com/dy/article/LANHT1QM0556KJNO.html)，媒体仍表述为「计划中」；权重版将移除部分网络安全训练数据。**建议下一步**：次日复核 HF 官方 org 页面；办公/表格场景 Agent 届时安排 1-2 天评测。

### 7. DeepSeek Super-agent 原型（Trial，第 2 周）

### 8. Postman 事件 + Agent 供应链安全（Trial 🆕）

### 9. 苹果国行 Apple 智能接入千问（Trial ✅ 今日开测兑现）
