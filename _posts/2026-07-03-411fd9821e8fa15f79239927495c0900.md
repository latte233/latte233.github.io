## 本期速览

本周最大的逆转是 Claude Fable 5 与 Mythos 5 于 7 月 1 日全球恢复访问——美国商务部解除了对这两款模型的出口管制，结束了上期报告记录的受限状态，同时 Anthropic 6 月 30 日悄然发布了 Claude Sonnet 5。与此同时，美团于 6 月 30 日正式开源 LongCat-2.0，1.6 万亿参数 MoE 模型全程基于国产 ASIC 集群训练，已在 OpenRouter 上取得领先调用量，是"完全不依赖英伟达完成训练"的又一例证——华为 openPangu 2.0（505B/92B，512K 上下文）同日跟进开源，国产算力自主可控的路线本周迎来双重验证。

协议层面，Model Context Protocol 发布了自诞生以来最大规模的规范修订（2026-07-28 Release Candidate）：移除有状态会话、废弃初始化握手、新增 Extensions 框架（含 Tasks 和 MCP Apps），所有自建 MCP Server 都需要评估迁移成本。生态信任层面则出现裂痕：HN 热帖曝光 Claude Code 通过不可见 Unicode 隐写标记检测 API 转售和模型蒸馏行为（1400+ 点赞、近 400 条评论），几乎同时 Meta 被曝内部禁止工程师使用 Claude Code 和 Codex，理由同样是防范"被反向蒸馏"——AI 编程工具的信任问题正在成为行业焦点。

### 巨头入场

**美团 — LongCat-2.0**（6月30日）🏢

美团正式开源 LongCat-2.0，1.6 万亿参数 MoE 模型，是业界首个在五万卡国产算力集群上完成全流程训练与推理的万亿参数模型。VentureBeat 确认其"trained entirely on Chinese chips"且已在 OpenRouter 上取得领先调用量，综合能力对标 Gemini、GPT-5.5 和 Claude Opus。MIT 协议开源，定位为 Agentic Coding 场景的"大脑"核心，已集成 Claude Code、OpenCode 等主流 Agent 工具。

**华为 — openPangu 2.0**（6月30日）🏢

华为在 HDC 2026 上宣布的 openPangu 2.0 于 6 月 30 日起分批开源，含 Pro（505B/激活18B）与 Flash（92B/激活6B）两版本，均支持 512K 超长上下文。深度适配昇腾算力，单卡吞吐率达业界主流开源模型两倍。计划陆续开源预训练代码、后训练代码、训练算子等 7 大核心组件。

两起事件共同印证：国产算力全流程训练万亿级大模型的路径已被验证可行，这是对英伟达算力依赖问题的一次集中回应。

## 重点信号详解

### Claude Fable 5 / Mythos 5 恢复全球访问

**象限**：Models & Research
**环位**：Adopt

**是什么**：美国商务部于 6 月 30 日宣布解除对 Claude Fable 5 与 Mythos 5 的出口管制，Anthropic 随即于 7 月 1 日恢复这两款模型在英国、欧洲、印度等地区，以及 Claude Code 和 API 渠道的全球访问。

**为什么重要**：上期报告中，Fable 5/Mythos 5 因出口管制陷入访问受限状态；本次恢复意味着此前的不确定性正式解除，这是继模型本身发布后又一次影响其全球可用性的重大事件。对于依赖 Fable 5 做复杂重构和长周期 Agent 任务的团队，这是一个"确认可以放心长期依赖"的信号。

**当前状态**：全球范围恢复访问，Claude Code、API 等主要渠道均已开放。

**建议下一步**：如果此前因区域限制暂停了 Fable 5 相关评估，现在可以重新启动；同时关注 GPT-5.6 是否会在相同的出口管制时间线上跟进开放。

### LongCat-2.0 与 openPangu 2.0 双双开源

**象限**：Models & Research
**环位**：Trial

**是什么**：6 月 30 日同一天，美团开源 1.6 万亿参数的 LongCat-2.0（全程国产 ASIC 集群训练），华为开源 openPangu 2.0（505B/92B，512K 上下文，深度适配昇腾）。

**为什么重要**：两者共同验证了"完全不依赖英伟达 GPU 的万亿级模型全流程训练"路径的可行性，是国产算力自主可控叙事在 2026 年最具体的技术落地案例。LongCat-2.0 已在 OpenRouter 取得领先调用量，说明市场已经开始用脚投票。

**当前状态**：LongCat-2.0 MIT 协议开源，代码与部分权重已上线 GitHub/HuggingFace；openPangu 2.0 计划分批开源 7 大组件，Flash 版本已上线。

**建议下一步**：对于评估国产算力部署方案的团队，可安排 PoC 测试 LongCat-2.0 在 Agentic Coding 场景下的实际表现，并关注 openPangu 2.0 后续组件的开源进度。

### MCP 2026-07-28 Release Candidate

**象限**：Frameworks & Infrastructure
**环位**：Trial

**是什么**：Model Context Protocol 官方发布下一版规范的 Release Candidate，被称为"自 MCP 诞生以来最大规模的修订"：核心协议无状态化、移除 initialize 握手、废弃 Mcp-Session-Id 及三个核心原语、新增 Extensions 框架（含 Tasks 和 MCP Apps 两个扩展）、OAuth 2.1 对齐的授权加固，并首次引入 12 个月的正式弃用政策。

**为什么重要**：这是 breaking changes 级别的更新，所有自建 MCP Server 都需要评估迁移路径；对于依赖 MCP 生态做 Agent 工具集成的团队，这是一次不可忽视的架构调整窗口期。

**当前状态**：Release Candidate 阶段，正式版本预计 2026-07-28 发布。

**建议下一步**：如果团队维护自有 MCP Server，尽早阅读迁移指南评估改造成本；评估 Tasks 和 MCP Apps 两个新扩展是否适用于自身场景。
