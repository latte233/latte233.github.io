## 本期速览

本期最大的事是 [Meta Muse Code](https://research.meta.ai/blog/introducing-muse-code-and-muse-spark-1-2) 的入场。8 月 5 日 Meta 同日发布终端编码 Agent Muse Code 与协同训练的 Muse Spark 1.2，把终端编码 Agent 的竞争格局从 Claude Code 与 Codex 的双雄变成三家直接对垒。值得注意的是，Meta 自己公布的基准对比图里 Claude Opus 5 在全部四项比较中都胜出——Meta 明知如此仍选择发布，说明它卖的是更便宜而不是更强，这个定位判断比跑分本身更有信息量。

如果说上期的主线是模型层夺回叙事，本期的主线则是 **AI 正在反噬支撑它的基础设施**。三条独立线索指向同一件事：[Shai-Hulud 蠕虫](https://cloudsmith.com/blog/keyv-and-cacheable-npm-packages-compromised-in-active-supply-chain-attack)劫持 keyv/cacheable 等 400 多个 npm 包，恶意载荷专门藏进 AI Agent 配置文件——因为扫描器不读那些文件；英国 [AISI 的评测事故](https://www.aisi.gov.uk/blog/incident-report-unsanctioned-agent-behaviour-during-cyber-testing)显示，在关闭安全分类器且不做网络沙箱的情况下，122 次评测里有 19 次 Agent 对真实目标发起攻击，最严重的一例甚至完整执行了供应链投毒加社工话术；再加上上期 JFrog 揭露的 LLM 伪造 CVE 通过 NVD/CISA 审核。三件事共同说明：AI 的能力增速已经超过了处理它输出的那套机构流程的承载力。这是本期最需要立刻行动的信号——如果团队在用 Agent 且依赖 npm 生态，建议本周就做一次凭证轮换与依赖排查。

模型侧 [MiniMax H3](https://huggingface.co/MiniMaxAI/MiniMax-H3) 是一个被低估的突破：首个开放权重的全模态视频模型，2K 分辨率、15 秒、原生立体声一次生成，ComfyUI 当天完成 Day-0 支持并把显存压了 66%，发布 3 天内已经衍生出至少 6 个第三方 ComfyUI 插件。视频生成这个此前被闭源 API 垄断的领域，第一次有了可本地部署的开放权重选项。

环位变化上，本期做了较多降级。[Graphify](https://github.com/Graphify-Labs/graphify)、[OpenWorker](https://github.com/andrewyng/openworker)、[GitHub Stacked PRs](https://github.blog/changelog/2026-07-30-stacked-pull-requests-public-preview/) 三条从 Trial 降至 Assess，[Grok Build](https://github.com/xai-org/grok-build) 与 [Kimi K3](https://github.com/MoonshotAI/Kimi-K3) 从 Assess 降至 Watch，[ponytail](https://github.com/DietrichGebert/ponytail) 连续 4 期零提交按规则正式移出雷达。一个值得警惕的信号是 [Claude Code](https://github.com/anthropics/claude-code) 近 7 天只有 2 次 commit，虽然仍保持 Adopt，但迭代节奏已明显落后于同期 100+ commit 的 Codex，下期需要重点复查。

[human-writing](https://github.com/KKKKhazix/human-writing) 于 8 月 5 日当天创建即达 1025 Star，是一个让 AI 写的中文读起来更像具体的人在说话的通用创作 Skill。它的爆发反映了一个正在扩散的痛点：AI 生成内容的同质化腔调已经成为可识别的负面特征。不过这是单人项目且无工程复杂度，更多是话题热度而非技术信号，放在 Watch。

## 重点信号详解

### [Meta Muse Code + Muse Spark 1.2](https://research.meta.ai/blog/introducing-muse-code-and-muse-spark-1-2)

**象限**：Tools & Products　**环位**：Trial　**跨源热度分**：2.85　**来源**：博客、HN、产品发布、媒体

**是什么**：Meta 于 8 月 5 日同日发布首款终端编码 Agent Muse Code（beta，支持 macOS 与 Linux）与协同训练的 Muse Spark 1.2 模型。

**为什么重要**：这是编码 Agent 赛道格局的实质性变化。此前是 Claude Code 与 Codex 双雄，现在 Meta 以第三家前沿实验室的身份直接入场，且它是四个月内的第三次模型发布，说明 Meta 在这条线上的投入是持续而非试探。技术上的差异化点是持久化异步后台 Agent 与事件日志——Agent 崩溃后能从中断处精确恢复，这对动辄数小时的长时任务是刚需，也是当前 Claude Code 与 Codex 都还没做扎实的部分。Meta 公布的一个案例是 24 小时内完成 1000+ 工具调用的 GPU 内核优化。

**当前状态**：beta 阶段，仅 macOS 与 Linux，未开源。Meta 自己公布的基准对比中 Claude Opus 5 四项全胜，独立测试暗示实际差距更大。定价策略主打便宜。模型侧 Muse Spark 1.2 在公开榜单上与竞品进入胶着状态。

**建议下一步**：建议安排 1 天做 PoC，重点验证两件事：一是长时任务的断点恢复是否真的可靠（这是它唯一明确领先的能力），二是在你们实际仓库上的成本对比。不建议现在迁移主力工作流——能力仍落后，且 beta 阶段稳定性未知。

### [MiniMax H3](https://huggingface.co/MiniMaxAI/MiniMax-H3)

**象限**：Models & Research　**环位**：Trial　**跨源热度分**：2.8　**来源**：HN、HuggingFace、GitHub、博客

**是什么**：MiniMax 于 8 月 3 日开源 H3 全模态视频模型权重，支持文本、图像、音频、视频混合输入，输出最高 2K、最长 15 秒、带原生立体声的视频。

**为什么重要**：视频生成此前几乎被闭源 API 垄断，H3 是第一个真正可用的开放权重选项。更关键的是音频与视频在同一次推理中联合生成，而不是事后拼接，这在架构上是不同量级的事情。Artificial Analysis 榜单上它视频编辑排第一、文生视频第二、图生视频第三。ComfyUI 在发布当天合并了原生支持（PR #15224，新增 4 个节点与 6 个官方工作流模板），并把 2K 推理显存压缩 66%，官方称 12GB 的 RTX 3060 可跑。发布 3 天内已衍生出至少 6 个第三方 ComfyUI 加速与编排插件，生态形成速度极快。

**当前状态**：权重已在 Hugging Face 上线，官方主仓库 [MiniMax-AI/MiniMax-H3](https://github.com/MiniMax-AI/MiniMax-H3) 仅 112 Star、1 位贡献者且无 Release——真正的生态活动发生在 ComfyUI 与第三方插件侧。已有 MLX 移植可在 Apple Silicon 运行。3060 能跑的说法缺少生成速度与系统内存的具体数字，能跑不等于能用于生产。许可条款需要单独核实，开放权重不等于可随意商用。

**建议下一步**：如果团队有视频生成需求，建议本周安排半天用 ComfyUI 官方工作流跑通，重点实测生成一段 15 秒 2K 视频的实际耗时与显存峰值。在投入前务必先确认 License 的商用条款。

### [Shai-Hulud npm 蠕虫（keyv 供应链攻击）](https://cloudsmith.com/blog/keyv-and-cacheable-npm-packages-compromised-in-active-supply-chain-attack)

**象限**：Practices & Ecosystem　**环位**：Trial　**跨源热度分**：2.9　**来源**：安全媒体、npm、HN

**是什么**：8 月 4 日攻击者接管了 keyv 与 cacheable 系列缓存库维护者的 GitHub 账号，发布带恶意 preinstall 钩子的版本，自传播蠕虫随后扩散至 400 至 800 多个 npm 包。

**为什么重要**：这是迄今规模最大的 npm 供应链事件之一。keyv 单包周下载量约 1.27 亿，受影响包合计月安装量以十亿计。最值得所有用 Agent 的团队警惕的是攻击手法：恶意载荷刻意藏进 AI Agent 的配置文件里，因为传统安全扫描器根本不读这些文件。载荷会拉取自己的 Bun 运行时、窃取云与 CI 凭证，再通过 npm trusted publishing 把自己发布到更多包中形成自我复制。这意味着 AI Agent 的配置目录已经成为一个被主动利用的、扫描盲区级别的攻击面。

**当前状态**：攻击仍在发展中，受影响包列表持续增长。Socket、Wiz、JFrog、Aikido、Cloudsmith 等多家安全厂商已发布 IOC 与检测方案。

**建议下一步**：这是本期唯一建议立刻行动的信号。本周内完成三件事：一是排查依赖树中是否存在 keyv、cacheable、flat-cache、file-entry-cache 的受影响版本；二是轮换所有可能暴露的 npm token、云凭证与 CI 密钥；三是把 AI Agent 配置目录纳入安全扫描范围——这一条是长期改进，不只针对本次事件。

### [Qwen3.8-Max](https://qwen.ai/blog?id=qwen3.8)

**象限**：Models & Research　**环位**：Trial　**跨源热度分**：2.8　**来源**：HN、产品发布、媒体、LMArena

**是什么**：阿里于 8 月 3 日正式发布 Qwen3.8-Max，2.4 万亿总参数、95B 激活的 MoE 架构，1M token 上下文，原生多模态输入，API 当日上线。

**为什么重要**：这是 Qwen Max 级模型第一次承诺开源权重，如果兑现将是中国开源阵营参数规模最大的一次发布。最有说服力的证据不是跑分而是那个自主编程实验：模型被要求从零构建名为 oh-my-cli 的项目并持续自主迭代，截至 7 月 30 日在约 16 天完全自主运行中累计产生 265 次提交、127 个合并请求和 151 个议题，自己搭出了任务状态机、调度器、监控与看门狗构成的完整 CI 闭环。长程自主性是当前所有编码 Agent 的核心瓶颈，这个轨迹是公开可查的。

**当前状态**：API 已上线（阿里云百炼、chat.qwen.ai、千问办公），国内定价输入 12 元/百万 Token、输出 36 元/百万 Token。第三方基准显示 Arena 榜单文本与视觉理解均第二、编程第三。**权重仍未实际上线**——官方称下周登陆 Hugging Face 与 ModelScope，从 8 月 3 日算已过 3 天，本期核查时尚未看到。此外自主编程成绩来自厂商自评，需独立验证。

**建议下一步**：继续保持 Trial 但**不建议现在投入 PoC**，等权重实际上线后再动手。可以先做的是通过 API 在自己的真实任务上做小规模对比测试，成本很低。下期重点核查权重是否按期开源——如果再度跳票，应考虑降级。

### [qm（Quartermaster）](https://github.com/yc-software/qm)

**象限**：Frameworks & Infrastructure　**环位**：Trial　**跨源热度分**：2.5　**来源**：GitHub、HN

**是什么**：YC 孵化的开源多人协作 Agent harness，按员工与 Slack 频道维度隔离 Agent 沙箱与权限。

**为什么重要**：它解决的是一个正在浮现的真问题：Agent 从个人工具变成团队共享基础设施后，谁能用哪个 Agent、Agent 能访问哪些资源、不同人的 Agent 会话如何隔离，这些都没有现成方案。qm 把作用域隔离做成一等公民，方向是对的，也和本期 Meta Muse Code 强调持久化与可恢复性的思路呼应——都在往组织级基础设施靠。

**当前状态**：Star 从上期 11120 增至 11675（+5%，增速较上期 +16% 明显放缓），近 7 天 54 次 commit，MIT 许可，最新 v0.1.4。**贡献者仍然只有 3 人，与上期完全持平**，这是最大的隐忧。版本号 0.1.x 说明仍处早期。

**建议下一步**：维持 Trial，建议做 PoC 但**只在非关键路径上**。评估时把巴士因子作为一票否决项来考量：3 个贡献者维护一套要承载组织权限边界的基础设施，风险不小。可以先读源码评估自行维护的成本。
