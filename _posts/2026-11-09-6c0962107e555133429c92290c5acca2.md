## 重点信号详解

### Anthropic IPO 冲刺与资本冷热镜像

**象限**：Practices & Ecosystem　**环位**：Adopt　**跨源热度分**：2.9

**是什么**：Anthropic 秘密递交 S-1 并于 11-02 修订（Q3 营收 170 亿美元、调整后营业利润 25 亿、算力承诺 8954 亿）；WSJ 称三大机构施压估值从 1.5 万亿降至约 1 万亿，路演本周启动、目标感恩节前挂牌，Kalshi 概率 84%→60%。招股书同时披露 9 月代码库 90%+ 贡献来自 Claude、人均日代码量为 2024 全年日均 45 倍，并预警或即将触及递归自我改进（RSI）门槛。

**为什么重要**：IPO 叙事正式从 OpenAI 换人——OpenAI CFO 已重申 2027 上半年 IPO（勘误上期「11-16 挂牌」），而 Anthropic 的「安全公司 + 高毛利」故事与 90% 代码由 AI 编写的披露，是 AI Coding 渗透率最权威的一手注脚。

**当前状态**：Kalshi 挂牌概率降至 60%，黑石预警 IPO 后或仅获垃圾级评级；镜像面：OpenAI 1.25 万亿估值融资首笔 110 亿交割（募资缩至 200 亿），中期选举周美股 AI 单日蒸发 2.3-2.8 万亿（口径不一）次日反弹，英伟达 11-17 财报为下一节点。

**建议下一步**：关注本周路演定价与缩募消息；营销/电商等应用团队可将「代码 90% AI 编写」作为内部 AI Coding 推广的对标数据点。

### Agent Skill 生态：大厂官方军备竞赛

**为什么重要**：Skill 生态从第三阶段的民间长尾爆发，正式转入大厂官方标配阶段——Skill 正在成为 Agent 能力分发的标准单元，平台卡位价值大于单项目价值。

**当前状态**：superpowers 等头部项目数据经 API 精确核验；caveman 属社区梗文化现象，反映 Agent 成本焦虑已成大众话题。

**建议下一步**：团队自建 Agent 能力库时优先对齐 Anthropic/Google 的官方 Skill 目录结构；低成本场景可快速试用 caveman 式提示词压缩。

### 开源模型军团：K3.1 Pro 权重兑现 + Hy4 Preview

**象限**：Models & Research　**环位**：Trial　**跨源热度分**：2.7

**是什么**：Kimi K3.1 Pro 2.8T 权重（MXFP4 1.56TB）11-05 上架 HuggingFace，Gated DSA 注意力内存降至稠密 MLA 约 23%，登顶 Agent Arena 开放权重榜、SuperCLUE 国产第一（61.46）；腾讯 Hy4 Preview（770B，34 项基准对 DeepSeek 赢 27 项）乌镇展出、权重仍待开源；Inkling 2 Small 同周发布。

**为什么重要**：这是连续数周「发布不落盘」后的集中兑现周——权重、榜单、部署工具链（vLLM 修剪版 4 卡可跑）三件事同时闭环，开源模型在 Agent 场景首次形成可用梯度。

**当前状态**：K3.1 Pro 原生需 12 张 141GB 卡，本地部署门槛仍高；DeepSeek V4.1 Base 权重核验确认未上架（上期待核实项关闭）；V4.1-Flash-1017 高热度但裸考 HLE 落后 Opus 5.0 达 13.7 分，需警惕榜单口径。

**建议下一步**：有 GPU 资源的团队可用 vLLM 修剪版做 K3.1 Pro 的 Agent 能力 PoC；其余保持关注 Hy4 权重落盘。

### Agent 治理与计量：Token 经济学

**象限**：Frameworks & Infrastructure　**环位**：Trial　**跨源热度分**：2.6

**为什么重要**：Agent 用量爆涨后，成本治理从工程细节升级为独立赛道，且首次出现巨头正面入场——预示 2027 年企业采购会把「Token 可观测性」列为标配需求。

**当前状态**：TokenEconomizer 数据 API 精确核验，Apache-2.0、活跃度高；竞品 caveman 属提示词级方案，工程化程度低。

**建议下一步**：安排 1-2 天 PoC：用 TokenEconomizer 对团队现有 Coding Agent 用量做一次基线测量。

### GPT-6.1 Terra 上架 AWS Bedrock

**象限**：Frameworks & Infrastructure　**环位**：Trial　**跨源热度分**：2.4
