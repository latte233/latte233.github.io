## 重点信号详解

### Kimi K3

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：3.0

**是什么**：月之暗面在 WAIC 2026 前夕发布的 2.8 万亿参数开源模型，成为全球参数最大的开源 LLM，支持 100 万 token 上下文，基于 KDA 混合线性注意力机制。

**为什么重要**：K3 上线 48 小时内算力告急暂停新订阅，直接导致 Nasdaq 半导体板块下跌 1.4%。这标志着中国开源模型从追赶转向引领，2.8T 参数 + 1M 上下文的开源组合此前从未出现过。K3 的 Agentic Coding 能力定位也可能改变 AI Coding 工具的模型选型格局。

**当前状态**：已开源，暂停新订阅以保障现有用户。315 亿美元估值。API 已上线。

**建议下一步**：安排 1-2 天在 Agentic Coding 场景做 PoC 验证，对比 Claude Code + Claude 模型 vs Kimi K3 的效果差异。关注订阅恢复时间。

### MCP 协议 2026-07-28 正式版

**象限**：Frameworks & Infrastructure
**环位**：Adopt
**跨源热度分**：3.0

**是什么**：MCP 协议自发布以来最大规模的版本更新，7 月 28 日正式版发布。核心变更：协议层无状态化（移除 session ID）、Extensions 框架、Tasks 扩展、MCP Apps、OAuth 2.1 对齐、12 个月弃用策略。

**为什么重要**：如果你自建了 MCP Server，session ID 将从协议层移除，Server 必须改造。RC 已于 5/21 发布，7/28 正式版后主流客户端将逐步切换。拖到正式版后再迁移就是被动跟进。

**当前状态**：RC 已发布，10 周验证窗口即将结束，7 天后正式版落地。

**建议下一步**：立即检查依赖的 MCP Server 是否有迁移计划，优先升级自建 Server 的无状态化适配。
