## 重点信号详解

### GLM-5.3-Flash 开源（Ox Alpha 揭晓）

**象限**：Models & Research
**环位**：Trial（维持）
**跨源热度分**：2.9

**是什么**：智谱开源 320B 总参/18B 激活的原生多模态 MoE，证实为此前匿名刷爆 OpenRouter 的 Ox Alpha，上下文 100 万 token，权重以 MIT 发布，定价 $0.15/$0.50 每百万 token（约为 Opus 4.8 的 1/40）。

**为什么重要**：匿名模型实测登顶再揭晓身份的路径证明了中国开源模型在真实流量下的竞争力；MIT 许可 + 极低定价会直接压缩闭门模型的成本敏感场景。

**当前状态**：权重已上架 Hugging Face 与 ModelScope（[模型卡](https://modelscope.cn/models/ZhipuAI/GLM-5.3-Flash)），AA 智能指数 v4.1.1 给出与 Kimi K3 并列的开源最高分。

**建议下一步**：在编码 Agent、工具调用与长上下文场景做受控基准评测（对比 GLM-5.3-Flash / Qwen3.8-Flash-Next / Kimi K3 三选型），验证 P95 延迟与成本后再决定是否进入生产候选池。

### Qwen3.8-Flash-Next

**象限**：Models & Research
**环位**：Trial（维持）
**跨源热度分**：2.8

**是什么**：阿里千问开源 125B 总参/6B 激活的多模态 MoE，原生 262K 上下文，多数基准超过 DeepSeek-V4-Flash，API 输入 1 元/百万 token，为 Qwen4 架构先导预览。

**为什么重要**：极低激活参数 + 新架构（稀疏注意力、新嵌入），代表下一代小激活高吞吐路线的公开样本，直接影响高并发推理成本结构。

**当前状态**：权重已上 Hugging Face/ModelScope，官方博客与媒体多源确认。

**建议下一步**：与 GLM-5.3-Flash 同批纳入三强选型评测，重点看 6B 激活在工具调用任务上的稳定性。

### Codex Harness（openai/codex）

**象限**：Frameworks & Infrastructure
**环位**：Trial（维持）
**跨源热度分**：2.9

**是什么**：OpenAI 开源的 CLI、SDK 与 app server 组合，把 Agent 执行环境做成可嵌入组件。

**为什么重要**：Agent 执行层正在组件化，Codex Harness 与 Claude 侧的插件/技能生态分别代表执行层与资产层的平台化竞争。

**当前状态**：119,198 Star、≥100 contributors、≥100 commits/7 天、Apache-2.0，健康度满分。

**建议下一步**：评估作为内部 Agent 平台执行层的候选，重点验证沙箱隔离与审批流（承接上期 OpenAI–HF 安全复盘的治理清单）。

### Claude/Cursor 插件与技能生态

**象限**：Tools & Products
**环位**：Trial（维持）
**跨源热度分**：2.7

**是什么**：Claude 官方插件库（34,677 Star）与 Cursor 官方插件规范（5,716 Star）先后开源，Agent 技能/插件分发进入大厂标准化阶段。

**为什么重要**：编码 Agent 的竞争从模型能力转向生态资产层，插件规范之争将决定未来两年工具链的锁定效应。

**当前状态**：claude-plugins-official 34,677 Star、14 commits/7 天；cursor/plugins 5,716 Star、43 commits/7 天但未声明 License。

**建议下一步**：把团队内部通用工具封装为兼容双规范的插件做小范围试点，同时盯住 cursor/plugins 的 License 声明进展。

### diagram-design

**象限**：Tools & Products
**环位**：Trial（⬆️ 由 Assess 上调）
**跨源热度分**：2.6

**是什么**：为 Claude Code/Codex/Pi 提供 38 种自包含 HTML+SVG 编辑级图表的技能资产库，本周 Star 爆发（约 +8,457/周，总量 27,942）。

**为什么重要**：验证了 Agent 技能从方法论走向垂直资产的商业路径，是本周 GitHub 生态最明确的趋势信号。

**当前状态**：MIT 许可，27 contributors，commits/7 天 5（内容库属性，低频提交正常）。

**建议下一步**：直接引入试用（成本极低），并以其为模板评估团队知识资产技能化（如内部 API 文档图表、监控大盘生成的技能化）。
