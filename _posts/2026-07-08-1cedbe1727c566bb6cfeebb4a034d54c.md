## 重点信号详解

### LongCat-2.0 万亿参数开源模型

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：2.8

**是什么**：美团 6 月 30 日发布并开源的 1.6 万亿参数 MoE 大模型，MIT 协议，全程使用 5 万卡国产 AI 芯片完成训练与推理，原生支持 100 万 token 超长上下文，SWE-bench Pro 59.5% 超越 GPT-5.5 的 58.6%。此前以匿名身份 Owl Alpha 在 OpenRouter 上领跑 Hermes 月调用量两个月。

**为什么重要**：这是中国开源大模型在编码能力维度首次在严苛基准上超越西方闭源旗舰。更关键的是全程使用国产芯片训练，证明美国芯片出口管制未能阻止中国训练前沿级模型。MIT 协议意味着任何企业可免费 fork、修改和商用部署，对高体积编码 Agent 工作负载提供了极具性价比的路径。

**当前状态**：模型已在 HuggingFace 和 longcat.chat 开放下载，OpenRouter 可直接调用。OpenRouter 匿名测试期间调用量全球第一（Hermes 月维度）和第二（Claude Code 月维度），社区验证充分。

**建议下一步**：在团队内部使用 OpenRouter 或本地部署进行编码能力对比测试，重点验证 Java/Go 后端代码场景的表现。同时关注 7 月中旬 DeepSeek V4 正式版发布后的横向对比。

### MCP 2026-07-28 规范正式版即将发布

**象限**：Frameworks & Infrastructure
**环位**：Adopt
**跨源热度分**：2.5

**是什么**：Model Context Protocol 2026-07-28 规范的正式版将于 7 月 28 日发布。这是协议史上最大规模修订：核心架构去状态化（移除 session 和 initialize 握手），新增 Extensions 框架（MCP Apps 服务端渲染 UI、Tasks 长任务扩展），鉴权向 OAuth 2.1/OIDC 对齐，并首次建立 12 个月正式弃用政策。

**为什么重要**：MCP 已被 Anthropic、OpenAI、Microsoft、Google 共同采纳，并捐赠给 Linux Foundation。此次规范发布将直接影响所有 MCP Server/Client 实现者的迁移路径，标志协议从实验期进入生产基础设施成熟期。

**当前状态**：Release Candidate 已于 5 月 21 日锁定，SDK 维护者有 10 周适配窗口。多家 MCP 生态项目已开始适配工作。

**建议下一步**：如果团队有 MCP Server 实现，立即启动 RC 适配工作。关注 7 月 28 日正式发布后的迁移指南和 Breaking Changes 文档。

### CodeGraph 代码知识图谱

**象限**：Frameworks & Infrastructure
**环位**：Trial
**跨源热度分**：2.3

**是什么**：为 AI 编码 Agent 构建本地预索引代码知识图谱的开源工具，基于 tree-sitter AST 解析 + SQLite FTS5 全文检索，实测减少约 57% Token 消耗、71-94% 工具调用次数，兼容 Claude Code、Cursor、Codex、Cline 等主流编码 Agent。

**为什么重要**：解决大型代码库场景下 AI Agent 探索阶段效率低下的核心痛点。58K+ Star 和 39 名贡献者的社区规模验证了市场需求。

**当前状态**：GitHub 58,322 Star，MIT 协议，TypeScript 实现，本周 61 次 commit，活跃开发中。已从爆发期进入稳定增长期。

**建议下一步**：在团队的主力项目中部署测试，对比接入前后的 Token 消耗和任务完成时间。重点关注大型 monorepo 场景的索引性能。
