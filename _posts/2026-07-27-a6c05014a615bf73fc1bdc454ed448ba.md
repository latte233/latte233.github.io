## 重点信号详解

### Claude Opus 5

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：3.0

**是什么**：Anthropic 于 7/24 发布的新一代 Opus 层级旗舰模型，1M 上下文，综合性能接近 Fable 5，定价仅为后者一半（$5/$25 per million token）。在 Frontier-Bench 上领先 Fable 5 +9.6 分，OSWorld 2.0 同样登顶。

**为什么重要**：这是前沿 AI 的「性价比拐点」。Opus 5 在 12 项基准中有 7 项超越 Fable 5，而成本减半。对于企业用户，这意味着以前因成本受限的 Agentic 工作流现在可以大规模部署。Claude Code 预计很快切换默认模型到 Opus 5。

**当前状态**：已全平台上线（claude.ai、API、Claude Code 可选）。SWE-bench Pro 略低于 Fable 5 0.8 分，网络安全任务弱于 Mythos 5。ARC-AGI 3 达到 30.2%。

**建议下一步**：立即评估将现有 Claude 工作流切换到 Opus 5。编程任务和一般知识工作场景下，Opus 5 是更优的默认选择。

### MCP 2026-07-28 无状态化正式版

**象限**：Frameworks & Infrastructure
**环位**：Adopt
**跨源热度分**：3.0

**是什么**：MCP 协议发布以来最大规模修订，明日（7/28）正式生效。核心变更：移除协议层会话和 initialize 握手，引入 Extensions 框架、Tasks、MCP Apps 概念，强化 OAuth 2.1 认证要求。

**为什么重要**：无状态架构意味着 MCP 请求可以命中任意服务器实例，解锁了水平扩展能力。这对生产环境部署 MCP 是根本性改进，但也意味着所有现有 MCP 服务器需要迁移。FastMCP v4.0.0a2 已在适配中。

**当前状态**：RC 已于 5/21 发布并经过 10 周验证。7/28 为最终发布日期。SDK 维护者已完成适配，但社区中仍有大量服务器使用旧协议。

**建议下一步**：如有自建 MCP 服务器，立即检查是否依赖会话状态或 initialize 握手，参照迁移清单完成适配。

### Kimi K3 权重开源

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：3.0

**是什么**：月之暗面（Moonshot AI）于 WAIC 2026 发布的 2.8T 参数 MoE 模型，1M 上下文，Modified MIT 许可。完整权重今日（7/27）正式在 HuggingFace 发布，成为全球最大开放权重模型。

**为什么重要**：K3 是首个突破 2T 参数的开放权重模型。AA Index 57.1 的成绩接近 Claude Fable 5 和 GPT-5.6 Sol。自托管方案需要约 18 张 H100 80GB（~1.4TB VRAM），Q4 MXFP4 量化后可降至可控范围。

**当前状态**：API 已上线（kimi.com、platform.kimi.ai）。权重今日发布，社区量化版本预计数日内出现。实际部署成本约 $50/hr（AWS/Azure 保留实例）。

**建议下一步**：关注社区独立 Benchmark 复现结果和量化部署方案。对数据驻留有要求的场景，K3 自托管是 Claude/GPT 闭源 API 的重要替代选项。

### Claude Sonnet 5 恢复活跃

**象限**：Models & Research
**环位**：Adopt（解除衰减预警）
**跨源热度分**：2.9

**是什么**：Anthropic 中端模型，1M 上下文，Claude Code 默认选择。上期连续 3 期无动态触发中度衰减预警，本期随 Opus 5 发布，Sonnet 5 在 Anthropic 模型阵列中重新定位明确——作为性价比最优的生产级选择。

**为什么重要**：Opus 5 的发布间接明确了 Sonnet 5 的生态位：不需要前沿推理能力的场景下，Sonnet 5 仍是最优选择。Anthropic 完整模型阵列（Fable 5 > Opus 5 > Sonnet 5 > Haiku）的定位至此清晰。

**建议下一步**：维持 Adopt，解除衰减标记。Claude Code 用户无需迁移。

### Stripe 洽购 OpenRouter（$10B）

**象限**：Practices & Ecosystem
**环位**：Assess
**跨源热度分**：2.7

**是什么**：支付巨头 Stripe 正洽谈以约 100 亿美元收购 AI 模型聚合平台 OpenRouter，后者此前估值仅 13 亿美元。OpenRouter 提供统一 API 接口调用 OpenAI、Anthropic、Google 等多家大模型。

**为什么重要**：这笔交易若成行，意味着支付基础设施和 AI 基础设施的深度整合。OpenRouter 已成为开发者调用多模型的关键中间件，Stripe 的介入可能将 AI API 计费变成「像刷信用卡一样简单」。对 OpenRouter 用户来说，短期内无影响，但长期定价和生态可能变化。

**建议下一步**：跟踪交易进展。如果你的应用依赖 OpenRouter 做模型路由，关注 Stripe 接手后的 API 稳定性和定价策略变化。
