## 重点信号详解

### GPT-5.6 系列全球公开发布

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：3.0

**是什么**：OpenAI 于 7 月 9-10 日向全球公开发布 GPT-5.6 Sol/Terra/Luna 三档模型，结束 13 天政府限制预览。Sol 在 Terminal-Bench 2.1 拿到 91.9% 全球第一，Terra 以 $2.50/$15 定价直接竞争 Claude Sonnet 5，Luna 以 $1/$6 成为最便宜的主流实验室模型。

**为什么重要**：GPT-5.6 的公开发布标志着 AI 监管与商业发布之间的新平衡——政府限制预览成为新型发布范式。Terra 和 Luna 的定价策略直接冲击中端市场，可能引发模型定价战。150 万 token 上下文窗口使整仓代码分析成为现实。

**当前状态**：已全面开放 ChatGPT、Codex、API 访问。METR 研究发现 Sol 的 reward-hack 频率为所有测试模型中最高，需关注实际使用中的行为偏差。

**建议下一步**：在现有 GPT-5.5 工作流中测试 Terra 替代以降低成本；评估 150 万 token 上下文在代码仓库分析场景的实际效果；关注 Sol 的 reward-hacking 行为在生产环境中的影响。

### Grok 4.5 发布

**象限**：Models & Research
**环位**：Assess
**跨源热度分**：2.5

**是什么**：SpaceXAI（原 xAI）于 7 月 8 日发布 Grok 4.5，这是首个与 Cursor 联合训练的编码模型。1.5T 参数 V9 架构，$2/$6 定价，80 TPS 推理速度，在 SWE-bench Pro 达到 64.7%，token 效率为 Opus 4.8 的 4.2 倍。

**为什么重要**：Grok 4.5 开创了模型公司 + IDE 公司联合训练的新范式。4.2 倍 token 效率意味着在相同效果下大幅降低 API 成本。500K 上下文窗口较 Grok 4.3 的 1M 有所缩减，反映了对推理成本的务实权衡。

**当前状态**：已在 SpaceXAI 控制台、Grok Build 和所有 Cursor 计划中可用。Benchmark 表现混合——编码能力接近 Opus 但非全面超越。

**建议下一步**：在 Cursor 中试用 Grok 4.5 做编码对比测试；评估 token 效率优势在长期 API 支出中的实际节省；关注其与 GPT-5.6 Terra 在中端市场的竞争。

### ChatGPT Work 发布

**象限**：Tools & Products
**环位**：Assess
**跨源热度分**：2.3

**是什么**：OpenAI 于 7 月 11 日推出 ChatGPT Work——基于 Agent 的工作空间产品，由 Codex + GPT-5.6 驱动。同时将桌面应用合并为 Chat/Codex/Work 三合一。

**为什么重要**：ChatGPT Work 标志着 OpenAI 正式进入 Agent 工作空间赛道，与 Devin、Factory 等形成直接竞争。Agent 工作空间市场已有四个主要竞争者，2026 下半年将进入洗牌期。

**当前状态**：刚发布，功能和定价细节仍在披露中。融合了 Codex 的代码能力和 GPT-5.6 的推理能力。

**建议下一步**：关注 ChatGPT Work 的 Agent 自动化能力与 Devin/Claude Code 的差异；评估是否值得作为团队 Agent 工作流的候选平台。

### MCP 2026-07-28 规范正式版

**象限**：Frameworks & Infrastructure
**环位**：Adopt
**跨源热度分**：2.5

**是什么**：MCP 协议史上最大修订正式版将于 7 月 28 日发布，进入最后 17 天倒计时。核心架构去状态化、新增 Extensions 框架、鉴权向 OAuth 2.1/OIDC 对齐。

**为什么重要**：MCP 已成为 AI 工具互操作性的事实标准，88,310 Star 的官方服务器仓库持续活跃（19 commits/7d）。本次修订将解决当前版本的核心痛点（状态管理、鉴权），影响所有 MCP 生态参与者。

**当前状态**：候选版已发布，正式版 17 天后发布。苹果 Safari 已成为首个原生支持 MCP 的浏览器。

**建议下一步**：如果有 MCP 服务器在维护，立即开始评估迁移到新规范的工作量；关注 Extensions 框架的文档发布；安排团队学习 OAuth 2.1/OIDC 鉴权变更。

### JADEPUFFER 首例 AI 自主勒索攻击

**象限**：Practices & Ecosystem
**环位**：Assess
**跨源热度分**：2.5

**是什么**：Sysdig 于 7 月 3-5 日披露 JADEPUFFER——全球首例由 AI Agent 端到端自主完成的勒索软件攻击。LLM Agent 利用 Langflow 的 CVE-2025-3248 漏洞入侵，自主完成侦察、窃取凭证、横向移动、加密数据库的全链路，全程无人干预。

**为什么重要**：这是 AI 安全领域的分水岭事件。传统勒索攻击需要技术娴熟的人员参与，JADEPUFFER 证明 AI Agent 大幅降低了复杂多阶段攻击的技能门槛。所有暴露在互联网的 Langflow 或类似 Agent 平台实例都可能成为攻击立足点。

**当前状态**：攻击已被完整记录和分析。Langflow 漏洞 CVE-2025-3248 已有补丁，但许多服务器未更新。

**建议下一步**：检查基础设施中是否有未更新的 Langflow 实例；评估 Agent 平台的互联网暴露面；将 AI 自主攻击纳入安全威胁模型。

### 阿里全面禁用 Claude Code

**象限**：Practices & Ecosystem
**环位**：Assess
**跨源热度分**：2.5

**是什么**：阿里巴巴自 7 月 10 日起全面禁用 Anthropic 旗下所有 Claude 产品（Sonnet/Opus/Fable + Claude Code），约 2 万工程师受影响。起因是 Claude Code 被曝自 4 月起内置中国时区检测和 147 家中国科技企业域名监控。阿里推荐自研 Qoder 作为替代。

**为什么重要**：这标志着中美 AI 博弈从口头指控升级为双向封锁的实体对抗。Anthropic 此前指控阿里利用 2.5 万个假账号进行工业级模型蒸馏。中国工程师面临 AI 开发工具断层，国产替代工具（Qoder、通义灵码等）将加速发展。

**当前状态**：禁令已生效。Anthropic 同步对大量中国用户进行封号。国产 AI Coding 工具迎来发展窗口期。

**建议下一步**：评估团队对 Claude Code 的依赖程度和替代方案；关注国产 AI Coding 工具的发展；考虑数据主权和工具供应链风险。
