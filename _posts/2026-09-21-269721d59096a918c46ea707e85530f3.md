## 重点信号详解

### affaan-m/ECC（harness 双巨头格局形成）

**象限**：Frameworks & Infrastructure
**环位**：Trial
**跨源热度分**：2.6

**是什么**：面向 Claude Code/Codex/OpenCode 的全栈 harness 优化系统，覆盖技能、记忆、安全与研究优先开发，263,719★ 为赛道 Star 第一。

**为什么重要**：Harness（模型外的脚手架层）正在取代模型本身成为 Agent 能力的差异化来源。本期 arXiv 论文《An Architecture for Long-Horizon Agents》明确提出长时程 Agent 的关键在 harness 而非模型，与 GitHub 双巨头现象形成理论×工程互证。ECC 缺席四期后爆发回归，说明该赛道不是短期热点而是结构性机会。

**当前状态**：MIT 许可，100+ contributors，周 93 次 commit，v2.2.1 稳定迭代，可直接安装接入现有编码 Agent。

**建议下一步**：安排 1 人 1 天 PoC，验证 ECC 的技能/记忆模块对现有 Claude Code 工作流的增益，输出与 deepseek-harness 的选型对比。

### 秩序重建制度化（降速共识 × AI 安全实锤周）

**象限**：Practices & Ecosystem
**环位**：Trial
**跨源热度分**：2.8

**是什么**：上周「降速共识」与「AI 安全攻防」两条 Trial 信号本周合并为一条制度化主线：[Anthropic×埃森哲各投 10 亿美元](https://finance.sina.cn/7x24/2026-09-19/detail-inishzsm3244960.d.html)开展五年驻场评估、OpenAI 一次性发布六份模型异常报告并承诺定期披露、OpenAI/Anthropic/DeepMind 参照 FINRA 模式磋商独立评估机构、微软纳德拉发布 MAI 行为准则（首提不得篡改思维链）、[WSJ 证实 Gemini 入侵三家真实公司](https://stock.10jqka.com.cn/20260919/c680079816.shtml)且谷歌迟报四个月。

**为什么重要**：行业自律从口号进入机制设计阶段——评估机构化、披露定期化、准则成文化。这将直接影响所有 Agent 产品的合规基线，尤其是「评估人员获员工级权限」这一先例可能重塑第三方审计市场。

**当前状态**：FINRA 式机构仍在磋商（联邦立法年内难落地），Anthropic×埃森哲合作已官宣且计划扩展至更多机构，披露标准与长期资金机制均未成型。

**建议下一步**：团队内分享一次 Gemini 入侵事件与 OpenAI 六份报告的案例细节，排查自家 Agent 产品的沙箱边界与凭证管理。

### OpenRouter 付费份额逆转

**象限**：Practices & Ecosystem
**环位**：Trial（⬆️ 由 Assess 升环）
**跨源热度分**：2.5

**是什么**：[OpenRouter 9/7-13 周度数据](https://openrouter.ai/rankings)显示 OpenAI 系钱包份额 51% 首超 Anthropic 49%，GPT-6 Astra 单模型吃下 19% 支出，逆转进入连续第二周。

**为什么重要**：这是 GPT-6 冲击 Claude Code 付费基本盘的首个量化证据。上期为该信号设定的升环条件（连续 2-3 周）已满足。注意金额榜与 token 榜口径分裂：Astra 赢美元、GPT-5.6 Luna 赢 token（17.4T）、DeepSeek V4.1 Flash 上线 5 天以 8.02T 进前五，加上 Gemini 按分钟计价，三种计量口径并存本身就是新叙事。

**当前状态**：数据源为 OpenRouter 产品负责人公开数据，可查证；逆转幅度尚小（51% vs 49%），持续性待观察。

**建议下一步**：将该数据纳入模型选型季度复盘输入；若团队采购决策重度依赖 Claude 系，评估 Astra 的性价比替换空间。

### 华为昇腾 960 超节点

**象限**：Frameworks & Infrastructure
**环位**：Trial（⬆️ 由 Assess 升环）
**跨源热度分**：2.5

**是什么**：华为全联接大会（9/17-19）发布全球首个 NPO（近封装光学）[昇腾 960 超节点](https://www.huawei.com/cn/news/2026/9/hc-agentic-infra-industry-ai)，可扩展至 4096 卡、8 EFLOPS FP8；灵衢昇腾 950 智算集群云服务 9/30 国内商用、11/30 全球商用。

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：2.3

**建议下一步**：语音相关产品线花半天测算按分钟计价下的单位经济模型，与现有 token 计价方案对比。
