## 重点信号详解

### MCP 2026-07-28 无状态化规范今日生效

**象限**：Frameworks & Infrastructure
**环位**：Adopt
**跨源热度分**：3.0

**是什么**：Model Context Protocol 2026-07-28 规范今日正式生效。这是协议史上最大修订：移除协议层会话和初始化握手，引入 Extensions 框架、Tasks、MCP Apps，强化 OAuth 2.1 授权，正式废弃 Roots、Sampling 和 Logging。

**为什么重要**：所有 MCP 服务端维护者面临迁移窗口。无状态化意味着服务端不再需要管理会话状态，大幅简化部署架构，但也要求现有实现做破坏性迁移。Extensions 框架使 MCP 从"工具协议"升级为"应用协议"。

**当前状态**：10 周 RC 验证窗口已结束，今日正式发布。主流 SDK（Python、TypeScript、Go）已发布兼容版本。[FastMCP](https://github.com/PrefectHQ/fastmcp) v3.4.5 已支持新规范。

**建议下一步**：立即检查团队使用的 MCP 服务端是否兼容 2026-07-28 规范，制定迁移计划。新项目应直接基于无状态架构开发。

### Claude Opus 5 — 近前沿半价

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：3.0

**是什么**：Anthropic 于 7/24 发布 Claude Opus 5，定价与 Opus 4.8 持平（$5/$25 per M token），仅为旗舰 Fable 5 的一半。Frontier-Bench 43.3% SOTA，SWE-bench Verified 96.0%，ARC-AGI 3 达次优三倍。

**为什么重要**：Opus 5 代表了前沿 AI 的"性价比拐点"——接近旗舰性能但半价。对于大量使用 Opus 4.8 的团队，同价升级即可获得显著性能提升。五档 effort 控制和默认思考开启改变了 API 调用模式。

**当前状态**：已上线 Claude API 和所有 Claude 平台。社区实测确认编程能力超越 Fable 5，但多模态和长任务能力仍需验证。发布一周，生态系统适配中。

**建议下一步**：已在用 Opus 4.8 的团队应立即升级到 Opus 5（同价）。注意两个破坏性变更：思考默认开启和 effort 参数。安排 1-2 天验证现有 Agent 工作流的兼容性。

### Kimi K3 — 全球最大开放权重模型

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：3.0

**是什么**：月之暗面 Kimi K3 完整权重于 7/27 如约开源，2.8 万亿参数，Modified MIT 协议，1M token 上下文。全球首个突破 2T 参数的开放权重模型。

**为什么重要**：开源阵营首次在参数规模上接近闭源前沿。Artificial Analysis 排名 57.1（3/189），虽落后 Fable 5（59.9）和 GPT-5.6 Sol（58.9），但已是近前沿水平。自托管可规避数据出境风险。

**当前状态**：权重已在 HuggingFace 发布，技术报告同步释出。Day-0 vLLM 支持已就绪。但 1.4TB 本地部署硬件门槛极高（需 8×H200 级别），实际自托管仍是大企业专属。

**建议下一步**：评估团队是否有自托管需求和能力。如有，可安排 PoC 验证 K3 在特定任务上的表现与 API 调用的差异。中小团队建议先用 API 验证再考虑自托管。
