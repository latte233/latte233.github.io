## 重点信号详解

### MCP 2026-07-28 无状态化正式版

**象限**：Frameworks & Infrastructure
**环位**：Adopt
**跨源热度分**：3.0

**是什么**：Model Context Protocol 自 2024 年 11 月发布以来最大规模的协议修订，7/28 正式生效。核心变更包括移除 Session 管理和 initialize 握手、强制 OAuth 2.1 接入、引入 Extensions 框架和 Tasks 概念。

**为什么重要**：所有部署了远程 MCP 服务器的团队都会受到影响——负载均衡不再需要 sticky routing，但每个请求需要自包含身份认证信息。这不是一个可以"暂时忽略"的更新，不兼容旧协议的客户端和服务器将在生效后出现连接失败。

**当前状态**：RC 已锁定（5/21），正式版今日生效。FastMCP v4.0.0a2 已适配。主流 IDE 集成（Cursor、Claude Code）预计将在数天内推送兼容更新。

**建议下一步**：立即对所有远程 MCP 部署执行迁移检查清单（参见 byteiota.com 的迁移指南）；验证 OAuth 2.1 token 流程；更新客户端 SDK 到最新版本。

### Kimi K3 权重开源

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：3.0

**是什么**：月之暗面（Moonshot AI）于 7/16 发布的 2.8T 参数模型，7/27 正式发布完整权重。全球首个超 2 万亿参数的开放权重模型，896 个专家中每次推理激活 16 个，支持 100 万 token 上下文。

**为什么重要**：Kimi K3 在前端编程（Code Arena 1679 分登顶）和长程任务中表现突出，Modified MIT 协议对商业使用友好。权重开放后，社区可以在本地部署和 fine-tune，对推动国产大模型生态有标志性意义。

**当前状态**：API 已上线，权重 7/27 发布。本地部署需要至少 18 块 H100 80GB（Q4 量化约 1.4TB VRAM），门槛较高但云部署方案（AWS/Azure/GCP）成本约 $50/hr。

**建议下一步**：等权重发布后，在 HuggingFace 或 ModelScope 上下载并评估其编程和中文理解能力是否适合团队场景；关注社区量化版本和更小参数蒸馏版本的发布。

### Grok 4.5

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：2.9

**是什么**：SpaceXAI 于 7/8 发布的旗舰模型，基于 1.5T 参数 V9 底座，与 Cursor 联合训练融入数万亿真实开发者编程交互数据。500K 上下文，支持 low/medium/high 三档推理，编程评测以 88 分登顶 Semgrep 基准。

**为什么重要**：Grok 4.5 定位"Opus 级但更快更便宜"——输入 $2/MTok、输出 $6/MTok，在编程场景下性价比显著优于 Claude Fable 5 和 GPT-5.6 Sol。SpaceX 收购 Cursor 后，Grok 与 Cursor 的深度集成可能成为 AI Coding 领域最强组合。

**当前状态**：已通过 xAI API 和 Cursor 内置可用，80 TPS 速度快于多数竞品。DeepSWE 和 SWE Marathon 评测均进入前三。

**建议下一步**：在 Cursor 中开启 Grok 4.5 试用，对比团队现有 Claude/GPT 模型在实际编程任务中的效果和成本。
