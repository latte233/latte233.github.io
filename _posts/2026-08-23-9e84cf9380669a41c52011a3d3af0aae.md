## 本期速览

本周最重磅的事件是 [DeepSeek 开源 deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)（口号"Everything is a Plugin"）：8 月 13 日创建，10 天收获 185,022 Star，社区随即涌现桌面版（18.3k Star）和插件目录（11.5k Star），生态扩散速度罕见。同周 [OpenAI 宣布全面开源 Codex Harness](https://github.com/openai/codex)（113,316 Star，近 7 天 100+ commits），Kimi K3 也被报道靠 Harness 工程逼近 Claude Opus 5。三条线索共振指向同一判断：**Agent 竞争的重心已从模型层转移到运行时（Harness）层**，与上周的技能资产化叙事形成连续趋势。

模型侧，[DeepSeek V4 视觉版](https://www.163.com/dy/media/T1489848170940.html)以"1 分钱 9 张图"的低价图像生成引发全网连夜实测；[Qwen3.8-Max](https://huggingface.co/Qwen) 开源生态持续扩展。资本面进入并购窗口：Stripe 拟 70 亿美元收购 OpenRouter，Anthropic Q2 营收破 115 亿美元并首次运营盈利（IPO 传闻估值 2 万亿美元），Etched 融资 7 亿美元、估值一月翻倍至 210 亿美元。

环位变迁：[claude-mem](https://github.com/thedotmack/claude-mem) 升入 Trial（91,529 Star、贡献者 100+、近 7 天 10 commits）；[superpowers](https://github.com/obra/superpowers) 连续 4 期近 7 天无提交，触发严重衰减预警，建议移出雷达。本期无新增 Adopt。建议下一步：用 1-2 天对 deepseek-harness 与 Codex Harness 做并行 PoC，评估可插件化运行时对现有研发工作流的适配成本。

## 重点信号详解

### DeepSeek Harness

**象限**：Frameworks & Infrastructure
**环位**：Trial
**跨源热度分**：3.0

**是什么**：DeepSeek 于 8 月 13 日开源的 Agent 运行时 v0.1（MIT），核心理念"Everything is a Plugin"，把技能、工具与沙箱统一为插件。

**为什么重要**：10 天 185k Star、社区桌面版与插件目录一周成型的扩散速度，说明开发者对"可插件化 Agent 底座"存在真实需求缺口；同周 OpenAI 开源 Codex Harness、Kimi K3 被 report 靠 harness 工程逼近 Opus 5，运行时层正在成为 Agent 竞争的新主场。

**当前状态**：MIT 开源、TypeScript、38 贡献者、窗口内 3 个 rc 版本、Open Issues 为 0；版本仍处 v0.1.x rc 阶段，生产采用案例尚少。

**建议下一步**：安排 1-2 天 PoC——用一个真实研发任务对比 deepseek-harness 与现有 Claude Code/Codex 工作流的完成率与改动成本；同时跟踪其插件 API 稳定性。

### OpenAI Codex Harness 全面开源

**象限**：Frameworks & Infrastructure
**环位**：Trial
**跨源热度分**：2.8

**是什么**：OpenAI 于 8 月 22 日前后将 Codex 的 Agent 运行时（Harness）全面开源，仓库 [openai/codex](https://github.com/openai/codex) 达 113,316 Star、近 7 天 100+ commits。

**为什么重要**：与 DeepSeek Harness 形成直接对垒，两大头部厂商同周押注运行时层开源，意味着"harness 工程化"从社区实践升级为平台级战略；对团队而言，编码 Agent 的可控性、可审计性从此有了可改造的开源底座。

**当前状态**：Apache-2.0、Rust、生态成熟；此前已有大量生产使用。

**建议下一步**：与 deepseek-harness 并行做对比 PoC，重点评估权限模型、沙箱机制与插件 API 的工程友好度。

### DeepSeek V4 视觉版

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：2.6

**是什么**：DeepSeek V4 系列的视觉版本上线，图像生成价格低至"1 分钱 9 张图"，8 月 20-22 日引发全网连夜实测刷屏。

**为什么重要**：把多模态生成的单位成本再压一个量级，直接冲击图像生成赛道的定价体系；与 DeepSeek API 生态（OpenRouter 周调用量第一）形成合力。

**当前状态**：API 已可用，社区实测内容密集产出，质量口碑整体正面。

**建议下一步**：有图像生成内部需求的团队可立即小批量接入做成本/质量对比；无直接需求则跟踪其定价对竞品的影响。

**象限**：Tools & Products
**环位**：Trial

**是什么**：Matt Pocock 维护的 Agent Skills 模板与目录范式，上期进入 Trial 后本周再增 2,550 Star（总量 231,997）。

**为什么重要**：连续两周高增长证明"技能资产化"不是脉冲热度；与 DeepSeek Harness 的插件化理念互为印证——工作流资产正成为可版本化、可复用的团队资产。

**建议下一步**：将现有研发工作流沉淀为 2-3 个 Skill 模板试运行，验证资产化收益。

### claude-mem

**象限**：Frameworks & Infrastructure
**环位**：Trial（⬆️ 上期为 Assess）
**跨源热度分**：2.6
