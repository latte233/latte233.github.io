## 重点信号详解

### deepseek-harness

**象限**：Frameworks & Infrastructure
**环位**：Trial
**跨源热度分**：3.0（GitHub + HN + 中外媒体刷屏级讨论）

动态：8 月 13 日与 DeepSeek V4 Pro 正式版同日发布，MIT 协议，主打「一切皆插件」的 Agent 运行时架构。创 GitHub 史上最快涨星纪录（1.5 小时 2.4 万 Star，45 小时 10.5 万 Star，当前 149.8k）。5 天内 Release 迭代至 dsh-v0.1.0-rc.7，社区插件（@文件引用、工作台侧边栏、纯文本模型补视觉）48 小时内涌现。

**判断**：模型厂商「模型 + 开源运行时」组合拳的开端。此前 Agent 运行时由独立社区项目（OpenClaw、deer-flow）主导，DeepSeek 是第一个亲自下场的基础模型厂商，可能引发其他厂商跟进。风险在于 rc 阶段 API 不稳定、贡献者仅 24 人、生态高度依赖 DeepSeek 自身模型竞争力。

**建议下一步**：安排 1-2 天 PoC——用 deepseek-harness 跑通一个内部编码/数据任务，重点验证插件机制与 DeepSeek V4 Pro 的协同收益，同时对比现有 OpenClaw 工作流迁移成本。

### Qwen3.8-2.4T-A95B 开源

**象限**：Models & Research
**环位**：Trial
**跨源热度分**：2.6（魔搭、凤凰科技、IT 之家等 5 源）

动态：8 月 13 日 Qwen-Max 级别模型首次开源权重：2.4T MoE 架构、激活 95B、原生 256K 上下文可扩展至 1M，PaperBench 取得较高成绩。叠加此前 Qwen 系列 HuggingFace 20.45 亿次下载登顶，阿里开源生态领先地位进一步巩固。

**判断**：闭源旗舰级模型权重首次开源，直接改变「旗舰能力只能买 API」的格局。对推理成本敏感、数据不能出域的团队是实质利好；95B 激活量对部署门槛要求仍高，需结合 SGLang/vLLM 生态落地。

**建议下一步**：在推理预算允许的前提下做一次与现有主力模型（DeepSeek V4 / GLM / Kimi）的同任务基准对比，重点看长上下文（256K+）场景。

### google/skills

**象限**：Practices & Ecosystem
**环位**：Trial
**跨源热度分**：2.5

动态：Google 官方 Agent Skills 仓库本周持续升温，18,438 Star（API 精确值），Apache-2.0，最近 commit 2026-08-17。与 superpowers（273k）、agency-agents（146k）构成同赛道三个量级。

**判断**：Agent Skills 品类从社区方法论（superpowers）进化到巨头标准化阶段。Google 背书意味着该品类可能成为 Agent 生态的下一个 MCP 级协议位。当前项目本身还很薄（6 贡献者、无 Release），价值在于卡位与信号意义。

**建议下一步**：持续观察 1-2 个月，看是否出现跨厂商技能包互认标准；团队内部可先在 superpowers 上试验技能化实践。
