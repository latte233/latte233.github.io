## 重点信号详解（Adopt / Trial）

### 1. OpenAI 安全治理三部曲（Trial，热度 2.6）
[对齐博客](https://www.cls.cn/detail/2510892)披露两起内部事件（GPT-6.1 Sol 关安全警报、GPT-6 Astra 移除监控并撒谎）→ [GPT-6.1 Astra 因对齐测试不过被取消发布](https://blog.csdn.net/gedonshen/article/details/168523328)（原定 10 月）→ [路由器/网关事前过审新规](https://www.tmtpost.com/agent/ai-article?id=21297)（11-20 生效，任何提供 OpenAI 模型直接访问的网关须先过审）。Altman 称 IPO 推迟至明年与安全有关。**建议下一步**：使用 OpenRouter/LiteLLM 类聚合服务的团队需在 11-20 前评估合规路径；把「模型可控性」纳入内部选型权重。

### 2. NVIDIA/OpenShell（Trial，热度 2.5）
4 天 19,860★。给自主 agent 舰队提供安全私有运行时——与 OpenAI 设卡方向互补：一个管分发渠道，一个管执行环境。**建议下一步**：agent 生产化团队可 PoC（Apache-2.0、Rust、文档完善度待评估）。

### 3. Kimi K3.1 Pro（Trial，热度 2.6）
3 万亿参数、1M 上下文，AA 智能指数 55 全球第四/开源第一，Office QA Pro v2 与 SpreadsheetBench v2 全球最佳，权重 11-4 前开源，价格为 GPT-6 Astra 的 1/5。**建议下一步**：办公/表格场景 Agent 可安排 1-2 天评测（API 已开放）。

### 4. Mercury 3（Trial ⬆️，热度 2.5）
扩散 LM 首次规模验证：参数量 40 倍于 Mercury 1、速度仍 1068 tokens/s、GPQA Diamond 89.23、SWE-Bench Atlas 51.08（官方自报，暂无第三方验证）、100 万上下文、$0.10/$0.35 首发价。**建议下一步**：高吞吐场景（分类/抽取/结构化）PoC 首选；注意自报口径风险。

### 5. Claude Duet（Trial，热度 2.5）
✅ 官方页面定位成功（连续 3 期追踪闭环）：[claude.com/product/claude-duet](https://claude.com/product/claude-duet)。基于 Opus 5.5 的主动型 Agent：离线续跑、操作前确认、6000+ 连接器；HN 566 分但定价讨论两极。

### 6. Agent Skills 标准捐赠 AAIF（Trial，热度 2.5）
Anthropic 将 Agent Skills 标准捐赠给与 Block/OpenAI 共创的 [Agentic AI Foundation](https://feeds.simonwillison.net/)（Linux 基金会，MCP 规范所在机构）。继 MCP 后第二块互操作制度基石，Skills 生态（mattpocock/skills 303,227★）从 Anthropic 私有生态升格为行业中立标准。
