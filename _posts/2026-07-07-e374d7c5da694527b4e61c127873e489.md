## 重点信号详解

### MCP 2026-07-28 规范候选版：协议史上最大重构

**象限**：工具
**环位**：Adopt（⬆️ 从 Trial 升级）

**是什么**：Model Context Protocol 团队于 5 月 21 日锁定 2026-07-28 规范的候选版本，这是协议发布以来最大的一次修订。核心变化包括：协议核心去状态化（移除 initialize 握手与 Mcp-Session-Id）、新增 Extensions 框架（MCP Apps 支持服务端渲染 UI、Tasks 扩展支持长任务）、鉴权体系向 OAuth 2.1/OpenID Connect 对齐、首次建立正式的 12 个月弃用政策。正式版将于 7 月 28 日发布，此前有 10 周验证窗口供 SDK 维护者和实现者适配。

**为什么重要**：无状态核心架构意味着 MCP Server 可以运行在普通 HTTP 基础设施上而无需专门的会话管理，这大幅降低了规模化部署的复杂度。对于已经自建 MCP Server 的团队，这是一次不可忽视的破坏性变更，需要评估迁移路径；对于正在做 Agent 基础设施选型的团队，"是否支持无状态 MCP"应当成为新的评估项。

**当前状态**：候选版已锁定，处于 10 周验证窗口内，正式发布定于 7 月 28 日。

**建议下一步**：如自建 MCP Server，尽快评估无状态化改造成本；如为 MCP 客户端/工具重度用户，关注上游依赖的迁移时间表，避免服务中断。

### CodeGraph：本周 GitHub 最大黑马

**象限**：工具
**环位**：Trial（新增）

**是什么**：CodeGraph 是一个为 AI 编码 Agent（Claude Code、Cursor、Codex、Cline 等）设计的本地代码知识图谱引擎，基于 tree-sitter 做 AST 解析、SQLite FTS5 做全文检索、原生 OS 文件事件实时同步。核心洞察是 Agent 在处理代码任务时，大量 Token 和时间消耗在"发现阶段"（扫描目录、搜索符号、读取文件），而非真正的推理生成，CodeGraph 把发现阶段外包给预建索引。

**为什么重要**：实测数据显示可减少约 57% Token 消耗、71-94% 工具调用次数，直接解决大型代码库场景下 AI Agent 效率低下的核心痛点。一周内 Star 数即突破 5.8 万，是本期 GitHub 生态中增速最快的项目。

**当前状态**：项目创建仅半年，本周为爆发窗口期，Fork/Star 比率偏低（0.062）说明当前观望者远多于深度使用者，其长期稳定性和维护质量仍待观察。

**建议下一步**：在非核心项目中先行试用，验证 Token 消耗和响应速度的实际改善幅度，暂缓大规模生产环境采纳。

### Claude Science：AI 公司亲自下场做药物研发

**象限**：平台
**环位**：Trial（⬆️ 从 Assess 升级）

**是什么**：Anthropic 在旧金山"The Briefing: AI for Science"活动上正式发布 Claude Science 公开测试版，面向所有付费订阅用户开放，无需企业审核。平台集成 NVIDIA BioNeMo Agent Toolkit，提供 60+ 预配置科研工具，科学家可通过自然语言与数字 Agent 对话执行端到端研究流程，覆盖文献分析、实验设计、蛋白质建模等。同步宣布启动自研临床前药物发现项目，聚焦被大型药企视为商业回报有限的"被忽视疾病"领域，AlphaFold 联合开发者 John Jumper 已加盟 Anthropic 生命科学团队。

**为什么重要**：这标志着 AI 公司的业务边界从"向药企卖工具"转向"亲自下场做药物研发"，是过去一年 Anthropic 持续深耕生物领域的高潮。诺华、百时美施贵宝等跨国药企高管现身发布会，说明产业界对这一方向的认可度较高。

**当前状态**：公开测试版已向所有 Claude 付费订阅用户开放。

**建议下一步**：如所在团队涉及生命科学或药物研发相关业务，可关注 Claude Science 的测试反馈，评估其在早期靶点发现和文献综述场景的实用性。

### SWE-bench 刷分争议与 Terminal-Bench 2.1 崛起

**象限**：标准
**环位**：Assess（新增）

**是什么**：多篇技术分析指出，SWE-bench 在 2026 年被严重"刷分"，经复核约 19.78% 的"已解决"案例实际上是语义错误的假阳性。作为替代方案，Terminal-Bench 2.1 在真实终端环境中测试 Agent 的多步骤规划与端到端任务完成能力（从编译代码到训练模型再到搭建服务器），其排行榜与 SWE-bench 出现了显著的位次反转。

**为什么重要**：这揭示了当前主流 Agent 编码能力评测基准的可信度问题。厂商在宣传中引用的 SWE-bench 分数可能无法真实反映模型的实际编码能力，团队在选型时需要交叉参考多个基准，并对厂商宣传数据保持审慎态度。

**当前状态**：Terminal-Bench 2.1 排行榜已上线，与 SWE-bench 排名存在明显差异，行业尚未就哪个基准更具权威性达成共识。

**建议下一步**：在评估编码 Agent/模型能力时，建议同时参考 SWE-bench Verified 和 Terminal-Bench 2.1 两套排行榜，避免单一基准导致的选型偏差。

### 提示注入攻击正式纳入 CVE 体系

**象限**：安全
**环位**：Assess（⬆️ 从 Watch 升级）

**是什么**：提示注入攻击持续被验证为企业级 AI 系统最大的攻击面之一。CVE-2026-24299 是影响 Microsoft Copilot 的提示注入漏洞，攻击者可通过在文档中嵌入隐藏指令使 Copilot 执行未授权操作，成为 AI 办公场景第一个具有里程碑意义的安全漏洞。微软安全团队同时披露了多个 AI Agent 框架中"提示变命令"（prompts become shells）导致远程代码执行的研究案例。

**为什么重要**：AI 安全威胁正式进入传统 CVE 漏洞管理体系，意味着企业安全团队需要将 Agent、RAG 管道、模型路由器纳入常规漏洞评估流程。当 AI Agent 具备浏览网页、执行代码、发送邮件、调用外部 API 的能力时，一次成功的提示注入不再只是聊天机器人的尴尬故障，而可能是完整的系统入侵。

**当前状态**：CVE-2026-24299 已被正式收录，相关研究和防护方案仍在持续更新中。

**建议下一步**：审查团队内所有具备执行权限的 AI Agent 系统，确认是否存在提示注入导致的越权风险，尤其关注处理外部文档、网页内容的 RAG 管道和自动化 Agent 工作流。
